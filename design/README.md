### 序厅方向定案 ·《炉前》（S10，2026-09-18）

**S09 是过渡稿，已作废。** 原因：S09 只解决了"那件雕塑长什么样"，而用户看过实拍后判断**"建模主题方向本身不对"** ——
原话「现在一看根本不知道是啥，要么换个方式吧」。
抽象流体的形态**没有参照物可对**：规格写得再细，实现方忠实执行后仍会被读成管子 / 象鼻 / 钩子；
而且"低模 + 流体"本身自相矛盾（流体感来自高面数，合并网格必然块面化）。

**S10 换的不是参数，是方法**：

| | 旧（作废） | 新（S10） |
|---|---|---|
| 主体 | 一件抽象雕塑 | **一个空间**（炉壁 + 炉口 + 铁水沟） |
| 形态来源 | 文字描述的连续曲面 | **房间已有坐标 + 一组开口尺寸** |
| 观众动作 | 看一件东西 | **站在炉前** |
| 一眼可命名性 | 靠抽象形态猜 | 由"发光洞口 + 流到脚边的铁水"直接给出 |
| 形态风险 | 高（无参照物） | 极低（盒体 / 放样 / 一个开口） |

`S10-序厅炉前基准.png` 三块内容：

1. **正立面** —— 46 × 18 m 炉壁（沿用现后墙）、**12.0 × 7.5 m 拱顶炉口**、底标高 +1.20、墙厚 0.60、
   护炉钢构柱位与横梁标高、检修门与烟道、下缘那对收口梯形＝铁水沟的透视缩短段；带 1.7 m 人形比例参照。
2. **侧剖** —— 纵深在哪：**炉膛净深 5.0 m** 的凹腔、从炉口斜下 20 m 的铁水沟、熔池、观众视线。
3. **亮度分层 + 4 条判据** —— ① 炉膛内芯 ≥200/255 · ② 内衬深段 ≥140 · ③ 内衬浅段 60…140 · ④ 墙角 ≤60，且 ①−④ ≥ 140；
   **主判据是 default 机位截图给 3 人盲测**（≥2 人说「炉子 / 炉火 / 铁水」→ 通过，须记原话）。

> ⚠️ **2026-09-20：E5 ②③ 口径已修订** —— **阈值一个都没动**，但 ②③ 的**采样位置**
> 从「墙面」移到了「炉口内衬（`furnace_lip`）」上。
>
> 原因：②③ 原来采的是**墙面**（法线朝观众），而全场景唯一能造光晕的「炉膛内芯」`PointLight`
> 在墙**背面**的炉膛里（`z −16.5` vs 墙 `z −14.6`）→ **背光，点积为负，物理不可达**；
> §8 又把 bloom / 贴图 / `AmbientLight` / 顶点色假辉光全禁掉。实测 ② 21.9 **比 ④ 墙角 24.0 还暗** ——
> 连「单调递减」都不成立，说明**分层根本没发生**。这是规格缺陷，不是实现问题。
>
> 处置：在洞口内加一圈**朝炉膛收口的发光内衬**，②③ 改采在它的深 / 浅两段上。
> 上面 4 个色块中的 ②③ 已换成该内衬的两个**实际顶点色**（`#F08A4A` / `#A8481F`）。
> 现行依据 = `spec/ENTRANCE-LIP-SPEC.md`；提示词 = `archive/spec/PROMPT-ENTRANCE-LIP.md`（**已实现，不要重发**）。

> 与 S07 的关系：**S07 定版式（HUD / 药丸 / 信息卡 / 说明条的位置），S10 定序厅里是什么东西。**
> S07 那屏按 `spec/ENTRANCE-FURNACE-SPEC.md` §7 只换五处**文字**，版式、位置、尺寸、颜色一律不动。

### 序厅视觉重修（S09）· 留档

**已作废（2026-09-18）**，图片已移入 `archive/design/S09-序厅形态与光影基准.png`。
文字结论**留在本文**，因为那 10 条诊断正是换方向的依据 —— 不要连它也一起清掉。

Step 4 首次交付后，设计方判断 S07 的雕塑**不可接受**：它被读成"一根深色的管子 / 象鼻"。
根因是**设计方的规格缺陷** —— 用文字描述了一个三维形态（"12 段变半径圆柱"），实现方忠实执行，
就得到了一根管子。**文字描述形态必然失真，这一轮改成交外轮廓。**

S09 那张图当时是补救措施，含四块内容：目标剪影正面 / 截面示意（圆管 ✗ vs 扁带 ✓）/
打光与材质 / 4 条量化判据。**补救失败** —— 抽象流体的形态没有参照物可对，
规格写得再细仍会被读成别的东西。这才是最终换方向（S10）的原因。

> **结论（比 S09 本身重要）**：**当形态没有参照物时，靠写规格去救是无效的。**
> 正确做法是换成一个**已有坐标 + 一组开口尺寸**就能定义的东西（见 S10）。
