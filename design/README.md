### 序厅方向定案 ·《炉前》（S10，2026-09-18）

**S09 是过渡稿，已作废。** 原因：S09 只解决了"那件雕塑长什么样"，而用户看过实拍后判断**"建模主题方向本身不对"** ——
原话「现在一看根本不知道是啥，要么换个方式吧」。
抽象流体的形态**没有参照物可对**：规格写得再细，实现方忠实执行后仍会被读成管子 / 象鼻 / 钩子；
而且"低模 + 流体"本身自相矛盾（流体感来自高面数，合并网格必然块面化）。

**S10 换的不是参数，是方法**：

| | 旧（作废） | 新（S10） |
|---|---|---|
| 主体 | 一件抽象雕塑 | **一个空间**（炉壁 + 炉口 + 铁水沟） |
| 形态来源 | 文字描述的连续曲面 | **房间已有坐标 + 一组开口尺寸** |
| 观众动作 | 看一件东西 | **站在炉前** |
| 一眼可命名性 | 靠抽象形态猜 | 由"发光洞口 + 流到脚边的铁水"直接给出 |
| 形态风险 | 高（无参照物） | 极低（盒体 / 放样 / 一个开口） |

`S10-序厅炉前基准.png` 三块内容：

1. **正立面** —— 46 × 18 m 炉壁（沿用现后墙）、**12.0 × 7.5 m 拱顶炉口**、底标高 +1.20、墙厚 0.60、
   护炉钢构柱位与横梁标高、检修门与烟道、下缘那对收口梯形＝铁水沟的透视缩短段；带 1.7 m 人形比例参照。
2. **侧剖** —— 纵深在哪：**炉膛净深 5.0 m** 的凹腔、从炉口斜下 20 m 的铁水沟、熔池、观众视线。
3. **亮度分层 + 4 条判据** —— ① 炉膛内芯 ≥200/255 … ④ 墙角 ≤60，且 ①−④ ≥ 140；
   **主判据是 default 机位截图给 3 人盲测**（≥2 人说「炉子 / 炉火 / 铁水」→ 通过，须记原话）。

> 与 S07 的关系：**S07 定版式（HUD / 药丸 / 信息卡 / 说明条的位置），S10 定序厅里是什么东西。**
> S07 那屏按 `spec/ENTRANCE-FURNACE-SPEC.md` §7 只换五处**文字**，版式、位置、尺寸、颜色一律不动。

### 真实遗产名《铁流凝变》的处置（已裁定 C · 折中）

**《铁流凝变》不是虚构名字，是真实馆藏**：一进正门的序厅，青铜浮雕，**22 × 11.5 m、净重 50 吨**，
**目前我国最大的工业题材青铜雕塑**，鲁迅美术学院两位教授设计，画面由「新中国第一炉钢水飞流直下」
演变出车间、塔罐群、齿轮、管线与工人（来源：中国日报网 2012-06-01；腾讯新闻 2026-06）。

S07 把序厅的**三维主角**换成了《炉前》，但下面这些写的是**真实博物馆**，**一律保留、不要清**：

- `home.js` 飞越章节 2「序厅《铁流凝变》」＋画布 S01 `3:56` / `3:70`
- `history.js` 头注「第 02 层 · 看懂 · 铁流凝变」
- `spec/PROJECT-BRIEF.md` §4 真实素材「序厅雕塑《铁流凝变》」

> **2026-09-18 用户裁定 C · 折中**：交互序厅的真实锚点落在**说明条**（`7:28`）——
> 「序厅镇馆铜雕《铁流凝变》· 长 22 m、高 11.5 m、重 50 吨 —— 这座炉子是它的一次再点火。」

### 序厅视觉重修（S09）· 留档

**已作废（2026-09-18）**，保留是因为那 10 条诊断正是换方向的依据。

Step 4 首次交付后，设计方判断 S07 的雕塑**不可接受**：它被读成"一根深色的管子 / 象鼻"。
根因是**设计方的规格缺陷** —— 用文字描述了一个三维形态（"12 段变半径圆柱"），实现方忠实执行，
就得到了一根管子。**文字描述形态必然失真，这一轮改成交外轮廓。**

`S09-序厅形态与光影基准.png` 是这张补救图，四块内容：

1. **目标剪影 · 正面** —— 外轮廓分 4 段（源头唇口 / 颈缩 / 主落片含指状分流 / 落点飞溅冠），
   外加 7 颗分离的空中液滴。**实现方的雕塑剪影必须与它对齐。**
2. **截面示意** —— ✗ 圆管（宽:厚 1:1）vs ✓ 扁带（宽:厚 ≥ 3:1）。这是"管"与"流淌的金属"的分界。
3. **打光与材质（顶视图）** —— 暖主光 + **冷轮廓光**（最关键）+ 地面光池；附 5 个色板。
4. **4 条量化判据** —— 可自查，不依赖人的主观判断。

> 与 S07 的关系：**S07 定版式（HUD / 药丸 / 信息卡 / 说明条的位置与文案），S09 定那件雕塑长什么样。**
> 两张都要看，缺一张都会做偏。

## ⚠️ 设计稿上已被新决策取代的细节
