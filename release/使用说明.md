# 中国工业博物馆数字展馆 · 可运行版

> 拿到这个文件夹的人，只需要做一件事：**双击 `启动.bat`**，浏览器会自动打开展厅。
> 无需联网、无需 npm install、无需构建、无需装任何依赖。

## 一、怎么运行

| 你的电脑上有 | 怎么做 |
|---|---|
| Node.js（推荐） | 双击 `启动.bat` 即可，浏览器自动打开 |
| 只有 Python 3 | 双击 `启动.bat` 也可以（自动走 Python 内置服务器） |
| 两个都没有 | 去 https://nodejs.org 装 Node.js LTS，然后双击 `启动.bat` |

命令行党也可以手动启动（效果相同）：

```
node server.js
```

或

```
python -m http.server 8080 --directory dist
```

然后浏览器打开 http://localhost:8080/ （展厅直达：http://localhost:8080/#/hall）

**停止服务**：关闭那个命令行窗口，或按 Ctrl + C。

## 二、⚠️ 常见错误：不要直接双击 dist/index.html

页面使用了 ES Module，直接从文件双击打开会被浏览器跨域拦截，**表现为白屏**。
必须通过本地服务器访问——上面任意一种方式都可以。

## 三、文件夹里是什么

```
release/
├── dist/          已构建好的成品网页（含 assets/ 与 fonts/，发给别人看，核心就是它）
├── server.js      零依赖本地服务器（Node 自带模块，无需安装任何包）
├── 启动.bat        Windows 一键启动
└── 使用说明.md     本文件
```

`dist/` 使用相对路径构建，放到任何静态服务器下都能跑
（Nginx、GitHub Pages、对象存储静态托管等均可，注意根路径或子路径都兼容）。

**字体声明**：`dist/fonts/` 内含 **霞鹜文楷 LXGW WenKai** 两个字体子集
（Regular / Bold，仅含本站用到的字形），按 **SIL Open Font License 1.1** 授权分发，
许可证全文见同目录 `OFL-LXGWWenKai.txt`；上游 https://github.com/lxgw/LxgwWenKai 。
字体随包本地加载，**断网也能正常显示**。

## 四、要继续开发 / 改代码

**源码不在本交付包里** —— 请到项目工作区的 `demo/` 目录：

```
cd demo
npm install
npm run dev
```

开发服务器地址以命令行输出为准（通常是 http://localhost:5173/ ）。

改完之后，在 `demo/` 目录执行 `npm run build`，
把生成的 `demo/dist/` 内容覆盖到 `release/dist/` 即可完成更新。

> ⚠️ 本包是 **2026-09-25 08:50 的构建快照**（十三批修订全部落地后：R1 体验修订、P0/P1 修订、
> 字体自托管并换装霞鹜文楷、圆角/字号收档、删 Inter 等）。源码在项目工作区 `demo/`，改动后重新构建覆盖即可。

## 五、局域网访问（可选，比如手机上看）

用 Node 方式启动时，把 `server.js` 里的 `HOST` 从 `'127.0.0.1'` 改成 `'0.0.0.0'`，
同一 Wi-Fi 下的手机访问 `http://<电脑IP>:8080/` 即可。
