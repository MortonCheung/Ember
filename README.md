# Ember · 《辽迹》

一座运行在浏览器里的**辽宁工业数字博物馆**。用户不通过导航菜单选馆，而是沿一条已经
策展好的路线从入口走到出口 ——

> 入口 → 沈阳·机器 → 过渡 → 鞍山·钢铁 → 下沉 → 抚顺·能源 → 终章 → 出口

同一条路线上有三个工业展品作为重点：走近时会主动提示「可以碰」，点进去可以绕着看，
退出后精确回到刚才站的位置；不点击就直接走过去。

参赛方向：2026 第五届辽宁省大学生虚拟现实与新媒体创新设计大赛 · 虚拟现实设计赛道 ·
文化创意方向。

## 当前阶段

**M0–M2 白盒已完成并通过自动验收。** 也就是说，"这座数字博物馆走起来对不对"可以被判断了；
展品仍是程序化白盒 Proxy，**尚未接入正式资产**。

- `#/journey` 连续博物馆骨架：单 Canvas、单 Scene、滚动驱动的相机路线、三个展品、Explore 闭环 ✅
- 早前原型的五条页面路线（首页 / 序厅 / 通史馆 / 铸造馆 / 亲手浇铸）**仍在正常运行**，
  它们提供了已经验证过的展品资产、工业空间和浇铸评分规则，会逐步并入正式产品 ✅
- 视觉细化 W2（序厅《炉前》建模）/ W3（浇铸互动）⏳ 未开始
- 数字工牌、协作车削 ❌ 未开始

## 启动

```bash
cd app
npm install
npm run dev        # http://localhost:5173/
```

Windows 可直接双击 `app/启动预览.bat`。完整说明（路由表、调试钩子、降级策略）见 `app/README.md`。

## 源码在哪里

```
app/
  index.html            页面外壳与样式引入
  src/
    app/                应用怎么启动、怎么路由
    pages/              六个路由页面入口，只负责组装页面
    museum/             博物馆这个三维世界本身
      viewport.js         Three.js runtime（renderer 生命周期 / resize / 资源回收）
      scenes/             已实现的工业空间：workshop / entrance-scene / cast-scene …
      exhibits/           正式工业展品资产：C620-1 车床 / 冲天炉 / 天吊 / 浇包 / 砂箱 / 工具车
      journey/            连续参观路线、镜头与 Explore 主线（产品骨架）
    features/casting/   浇铸体验功能：可解释评分规则与数据
    shared/             确实被多个领域共同使用的东西：WebGL 能力检测与降级、场馆导航
    styles/             Token 化原生 CSS，按页面拆分
tools/
  verify_journey.py     CDP 自动验收（唯一验收入口）
spec/
  README.md             哪些规格当前有效、哪些已归档
```

依赖方向：`pages` 组装一切；`museum` 提供三维世界；`features` 提供独立功能；
`shared` 是唯一被跨领域复用的层。**`shared` 不依赖任何其它层。**
完整规则见 `src/README.md`。

## 三条不能违反的产品约束

1. **空间是连续的。** 入口到出口属于同一个 Scene，切页式重建不是《辽迹》的做法。
2. **滚动是输入，不是翻页。** ScrollTrigger 只读进度，相机由 `CameraRig` 统一计算。
3. **一切互动必须可跳过。** 展品提示是邀请不是关卡；Explore 是同世界内的临时状态，
   退出后位置误差必须 ≤ 0.001（滚动 ≤ 2px）。
