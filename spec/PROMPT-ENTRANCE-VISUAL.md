## 上一版为什么"丑"（诊断，有实拍证据）

实拍里它被读成 **"一根深色的管子 / 象鼻 / 角"**，不是"钢水倾泻"。逐条原因：

1. **没有"源头"** —— 顶端是尖的、悬空的，物体失去因果方向，于是只能被读成动物器官。
2. **落点读不出"砸在地面上"** —— 3 个压扁锥横向展开不足。
3. **"飞溅"是散在地上的几个方块**，不是空中的液滴。
4. **横向环状台阶（竹节）** —— "38% 搭接"留下的环向棱线。**这是本版最刺眼的廉价感来源。**
5. **主体与背景没有分离**（丑的最大单一来源）—— 青铜 `#6B5B4A` + `metalness .8` + 唯一聚光 = 近黑，边缘糊进背景。
6. **没有轮廓光**。
7. **地面全黑 → 物体悬在虚空**；**后墙全黑 → 没有背景层次**。
8. **22 m 的物体被裁切** —— r=16.28 装不下。

> 其中只有第 4 条里"用搭接补豁口"是你的判断（你也如实标注了）；其余全部是设计方的规格缺陷。

## 做什么（五个改动，按重要性排）

### ① 重做形态 —— 照 `S09` 的外轮廓对

雕塑分四段 + 空中液滴：

| 段 | 占横向 | 内容 |
|---|---|---|
| **① 源头唇口** | 0–15% | 略粗的水平承接体，端部收成唇口（读作炉口/浇包口）。**没有它就会退化成"动物的角"。** |
| **② 颈缩** | 15–25% | 截面迅速收窄到 ①的 45% —— 离口被拉细的瞬间 |
| **③ 主落片** | 25–72% | 片状铺展（横 1.2 → 5.5 m），底缘带 **3–4 条指状分流** |
| **④ 落点飞溅冠** | 72–100% | 低矮蘑菇状 + 左右各一个回卷尖；**冠宽 ≥ 中段厚度 × 2** |
| **空中液滴** | 7 颗 | 直径 0.25–0.9 m，**必须在空中、与主体分离** |

**构造法（不要再用"多段圆柱接"）**：一条 `CatmullRomCurve3` 采样 **40 点**，每点放 **8 个环点**围成**扁矩形**
（宽 `w(t)` 0.5 → 5.5 m 用 `smoothstep`，厚 `h(t)` 0.35 → 1.6 m），按 40×8 索引成面。
**一条连续几何，天生没有段缝。** 每点的 `N`/`B` 用固定上向量 `(0,1,0)` 求（**不要用 Frenet，会翻转**）。

**四条禁令**：
- ❌ 不得用多个独立圆柱/棱柱"接"主带
- ❌ **不得靠搭接遮豁口** —— 搭接产生横向环状台阶（竹节），比豁口更难看。要消失的是**接缝本身**
- ❌ 不得用圆截面（宽:厚 全程 **≥ 3:1**，这是"管"与"流淌的金属"的分界）
- ❌ 不得有**横向**环状棱线（只允许沿流向的纵向凸棱，且不闭合成环）

### ② 材质提亮（**脱离"近黑"**）

`#6B5B4A → #9A7F5C`（亮约 40%）／`metalness .8 → .85`／`roughness .35 → .26`／`envMapIntensity .25 → .55`。

> 为什么 `envMapIntensity` 不同：铸造馆的 `.25` 是为大场景省预算，序厅只有一件主体，**别照抄**。
> 铁水橙纪律不破：**物体上不放橙色**。它是**凝固的**钢水。

### ③ 打光（**"好看"的最大杠杆**）

| 灯 | 参数 |
|---|---|
| 环境 | `HemisphereLight(0x2A3A4A, 0x14181D, 0.55)` |
| **主光 Key** | `SpotLight(0xFFF1E2, 4.5)`，`(4,16,10)` → `(0,5.4,0)`，`angle .34`/`penumbra .55`/`decay 1.3`/`distance 52`，**`castShadow`** |
| **轮廓光 Rim** ⭐ | `SpotLight(0x8FB4D8, 3.0)`，`(-6,12,-9)` → `(0,6,0)`，`angle .5`/`penumbra .7`/`decay 1.2`/`distance 44` |
| 地面光池 | `SpotLight(0xFFE9D6, 1.6)`，`(0,14,0)` → `(0,0,0)`，`angle .85`/`penumbra 1.0`/`decay 1.1`/`distance 30` |
| 补光 | `DirectionalLight(0xFFFFFF, 0.18)`，`(10,1.5,9)` |

**冷轮廓 + 暖主光是雕塑摄影的标准打法，也是"一眼高级"的来源。轮廓光不可省。**

### ④ 环境（把"黑洞"变成"展厅"）

- 地面：`PlaneGeometry(60,60)`，`0x131820`、`roughness .62`、`metalness .12`、`receiveShadow` —— 比现在亮一档，让光池显形
- 后墙：`PlaneGeometry(46,18)`，`0x171C24`、`roughness .9`，立在 `z=-14`
- **踢脚线**：墙底一条 **1.2 m 高**的暗橙条 `MeshBasicMaterial(0x3A241B)` —— 给空间一条地平线，画面立刻有纵深
- 侧墙/顶棚/灯具模型：**不做**

### ⑤ 机位（旧机位装不下 22 m）

| 预设 | pos → target | 半径 |
|---|---|---|
| `default` | `[0,3.2,23]` → `[0,5.6,0]` | 23.12 |
| `sculpture` | `[7.6,4.0,9.5]` → `[-1.2,4.4,0]` | 12.96 |
| `splash`（新增） | `[10.5,2.6,7.0]` → `[6.6,1.1,0]` | 8.15 |

> 三预设都 ≥ `minDistance + 0.05`（= 6.05）。**近观读数必须在 `setView()` 之后取，不得直算。**
