## §3 §8 未定项与冲突处的裁定（**本轮核心，逐条给依据**）

### §3.1 双人协作的落地定义：**同屏双角色，不联网**

`STEP3 §9` 明写「**无需后端** · 全部规则在前端纯函数中，无网络请求」。
所以「双人」= **两名同学共用这一台展厅设备**（`§10 E14` 的「防止长时间占用展厅设备」正是这个语境）。

- **徽标文案改**：画稿 `已连接 2/2` → **`双人协作模式 · 同屏操作`**。
  理由：`已连接` 暗示联网握手，而本作品无网络层 —— 与场馆导航「· 筹备中」是同一种**诚实降级**。
- **不做人数检测**（物理上做不到，也不该做）。两个滑杆**始终都可操作**。
- **协作分照算，不因单人而归零**（与 §8.1 原文不同，见下）。

> **对 §8.1「单人可开，但不计团队协作分」的修订**：
> §8.2 的协作分公式（时间差惩罚 + 匹配偏差惩罚）**只用两个参数的历史，不需要知道谁在按**。
> 单人操作时它依然有意义 —— 一个人一手一个滑杆，先后调整的时间差就是"配合度"。
> 所以：**协作分一律计算，界面不宣称人数。** 不引入任何无法验证的判定。
> 单人模式下由文案承担诚实性：若检测不到第二次"角色切换"（无可靠依据），**不加任何单人提示** —— 宁可不提示，也不做假判定。

### §3.2 计时：从**第一次调整参数**开始，到**车削动画结束**为止

§8.1 只写了起点（「计时从第一次调整参数开始」），**没写终点** —— 这是真空缺。

- **起点**：第一次 `input` 事件（拖动任一滑杆）。
  - 若**从未调整参数**就点「开始车削」：起点回退为**点击时刻**（否则无终点可算）。
- **终点**：**车削动画播放完毕的时刻**（塔轮车完），不是点击时刻。
  理由：若终点是点击，动画时长（§3.3 的 3600 ms）就对所有人免费 —— 而"等工件车完"是真实成本。
- **格式**：`mm:ss`（`Intl.NumberFormat` 或等价格式化，不散写 `toFixed`）。
- **上限**：`t > 600 s` 强制结算（`§10 E14`）。
- **入榜门槛**：质量分 ≥ 60 **且** `t ≥ 10 s`（`§8.3`）。低于 10 s 视为异常，**不入榜，但分数照常显示**。

### §3.3 车削动画：**固定 3600 ms**，与 n、f 无关

**必须固定**，否则用时口径不公（慢参数 = 长动画 = 双重惩罚）。

| 段 | 时长 | 内容 |
|---|---|---|
| A 起动 | 0–500 ms | 卡盘带工件起转（角速度 0 → 目标值），刀架从安全位进入 |
| B 切削 | 500–3200 ms | 刀架沿工件轴向走完 6 级台阶，逐级成形；切屑粒子从刀尖落 |
| C 收刀 | 3200–3600 ms | 刀架退回安全位，主轴降速停转 |

**参数 → 视觉映射（三条都要单调、可测）**：

| 参数 | 映射 | 说明 |
|---|---|---|
| `n` 主轴转速 | 视觉角速度 `ω = n / 400` rad/s（0.50 … 3.00） | **必须降速显示**：真实 620 r/min = 10.3 转/秒，60 fps 下就是一片糊。HUD 仍显示真实 r/min |
| `f` 进刀量 | 塔轮各级半径偏差 `ΔR = (0.30 − f) × 0.02` m | `f` 偏小 → 直径偏大（让刀不足）；`f` 偏大 → 直径偏小（让刀）。单调 ✓ |
| `f > 0.40` | 台阶面出现周向**刀痕暗环**，数量 `clamp(round((f − 0.40) × 25), 1, 8)` | `f` 越大环越多 —— 把「刀痕粗」变成看得见的东西 |

- 刀架轴向位置**只由动画进度驱动**：`z = −0.18 + progress × 0.36`（`easeInOutCubic`），**与 n、f 无关**。
- 工件几何：**毛坯是等径大圆柱（R = 0.085），车削中逐级缩到标称半径**
  `R_i = 0.075 − i × 0.010`（i = 0…5，共 6 级）。
  **必须做成 1 个 `BufferGeometry`（6 段 × 32 边），在 update 里改顶点** —— 约束是**工件只占 1 个 draw call**（§7.2）。
- **零随机**：切屑粒子的分布、刀痕位置全部由确定性函数（`sin` 哈希，同 cast 页做法）给出，**禁 `Math.random`**。

### §3.4 ⚠️ **滑杆初值必须偏离理想窗口**（画稿会让人「不动手」拿满分）

**先说清楚画稿是什么状态。** S04 画稿显示 `主轴转速 620 r/min` / `进刀量 0.32 mm/r`，
但它同时显示 `正在录制` + `本局用时 02:14` ——**画稿是「车削进行中」的一帧，不是初始态**。
那两个值是**进行中的读数**，不是初值。

**为什么不能照抄当初值**：620 落在 `n ∈ [560,760]` 内、0.32 落在 `f ∈ [0.20,0.40]` 内 ——
**两个都在理想窗口内**，意味着**玩家一个滑杆都不动就是满分参数**（§7.4 给了完整算例）。
而浇铸那边的初始态 `sandbox_8` 是**故意不理想**的（输出 72 分，`§10 E4`）。车削必须对齐这个设计。

**裁定：滑杆初值 = `n = 420 r/min` · `f = 0.52 mm/r`。**

| | 值 | 相对理想窗口 | 覆盖的扣分方向 |
|---|---|---|---|
| `n` | **420** | `[560,760]` 之下 → 积屑瘤 | 转速**偏低**分支 |
| `f` | **0.52** | `[0.20,0.40]` 之上 → 刀痕粗 | 进刀量**偏高**分支 |

- 两个初值分别踩中**两个不同参数**的**两个不同方向**，让玩家一眼看出"两边都要调"，而不是只调一个。
- **滑杆上的标签显示初值**（`主轴转速 420 r/min`），**不是**画稿的 620 —— 画稿那组是进行中值。
- ⚠️ `620` 是 C620-1 机床型号的呼应彩蛋，**不要从画稿上抹掉**；它只属于"进行中"那一帧。

### §3.5 术语：**「进刀量」（画稿）** vs 「进给量」（`§8.1`）

**对外文案一律用画稿的「进刀量」**（滑杆标签、诊断文案、工牌）。
`STEP3 §8.1/§8.2` 里的「进给量 `f`」是工艺学正名，**代码标识符用 `feed` / `f`**，
**面向用户的中文一律「进刀量」**。两者指的是同一个参数，**不要同时出现在同一条界面上**。

### §3.6 工件：固定为**塔轮（6 级台阶，HT200）**

- 与浇铸的叙事链：`STEP3 §3.1` 的 4 种铸件里就有**齿轮（塔轮）**——
  「铸出来 → 车到尺寸」是同一条工艺链，**这不是两个孤立的小游戏**。
- 文案上呼应即可（右栏说明已含赵国友与塔轮），**不强制**要求玩家必须先浇过齿轮箱。

### §3.7 排行榜：**本机榜单 + 馆内固定基准**（无后端）

`§8.3` 定了排序与门槛，但没说榜上那三行从哪来。**裁定**：

| 行 | 来源 | 说明 |
|---|---|---|
| `王工组 · 铁西分队` `01:48` | **写死的风格化基准**（`turning-data.js`） | 馆内固定参照，不随玩家变动 |
| `你与队友（本局）` | **本局实际用时** | 按 §8.3 排序规则（先质量分降序，同分按用时升序）**插到正确名次**；`--c-iron` 描边高亮 |
| `工博小志愿者队` `02:39` | **写死的风格化基准** | 同上 |

- 本局若优于 `01:48` → 升到第 1，其余下移；若劣于 `02:39` → 排末位。
- `历史纪录 00:50` 为**固定基准，永不改动**（`§8.3` 原文；对应赵国友 50 分钟）。
- `组内最佳` = `localStorage` 里本机最好成绩；无记录时显示 `—`。
- **榜脚须有一行小字**：`本机记录 · 含馆内固定基准`（约 11px，`--c-steel`）。
  理由：无后端却摆一个榜，**必须说清它是什么** —— 这是本项目「诚实降级」的一贯做法。

### §3.8 「录制与回放」怎么落

画稿 `正在录制 · 可回放出品过程` 是**明确的产品承诺**，不能做成装饰。

- **录制**：从计时起点开始，按**固定 100 ms 间隔**采样 `{ t, n, f }`，存内存数组（不写存储）。
- **回放**：结算态启用右栏**按钮行的第 2 枚 `回放本局`**（画稿未画 → **规格新增**；布局见 §2.3 第 8 项）。
  点击后：① 视口按记录的时间线**重演动画**（同一套 `update`，只把参数源换成记录）；② 右栏在计时值下方**叠加一条 `n` / `f` 的双折线**（SVG 或 canvas 2D 绘制，两条线分别用 `--c-iron` 与 `--c-text-muted`）。
- **零随机**：回放必须逐帧一致（同一份记录 ⇒ 同一画面）。

### 4.1 子项（权重 45 / 35 / 20）

```
表面质量：扣 = 0
  若 n < 560 : 扣 += min(40, (560 − n) × 0.35)      // 积屑瘤
  若 n > 760 : 扣 += min(30, (n − 760) × 0.30)      // 刀具磨损与颤振
  若 f > 0.40: 扣 += min(45, (f − 0.40) × 120)      // 刀痕粗
  表面质量 = max(0, 100 − 扣)

尺寸精度：m = n × f
  若 m > 304 : 扣 = min(35, (m − 304) × 0.35)       // 让刀、尺寸超差
  若 m < 112 : 扣 = min(25, (112 − m) × 0.20)       // 让刀不足
  否则 扣 = 0
  尺寸精度 = max(0, 100 − 扣)

用时：用时得分 = clamp(round(50 / t × 100), 0, 100)   // 50 s ⇔ 赵国友的 50 分钟，不要改
```

- **权重合成**：`总分 = 表面质量 × 0.45 + 尺寸精度 × 0.35 + 用时得分 × 0.20`
- `n < 560` 与 `n > 760` **互斥**（窗口连续），同一条规则不会同时命中。
- 同一子项内不同参数**可累加**（`§10 E5`）；同一参数同一子项**只取一条**（本来也只有一条）。
- 子项最低 0、总分最低 0，**不出现负分**（`§10 E1`）。

### 4.2 协作分（0–100，**不计入质量分**）

```
协作分 = 100 − 时间差惩罚 − 匹配偏差惩罚
时间差惩罚   = min(30, 累计时间差(s) × 2)
匹配偏差惩罚 = min(40, |f − 0.30| / 0.10 × 20 + |n − 660| / 100 × 20)
```

- `f` 理想带 `[0.20,0.40]` → 中值 `0.30`、半带宽 `0.10`
- `n` 理想带 `[560,760]` → 中值 `660`、半带宽 `100`
- **累计时间差** = 相邻两次参数调整的时间间隔之和（秒）。
  读法（见 §3.1）：**两个人协调得好 ⇒ 调整几乎同时发生 ⇒ 时间差小**；一个人来回犹豫 ⇒ 时间差大。
- **协作分下限 0**，不出现负值。

### 4.3 等级（用于工牌 `rank` 与本页徽标）

**与浇铸共用同一张映射表**（`§6.1`，`STEP3` 已定义，**不要另立一套**）。
车削页只在**质量分**上套用这张表做徽标；`< 60` 走「待复检」（不发等级）。

### 4.4 引擎纪律（同 `§12`）

- **纯函数**：`score({ n, f, t, adjustments }) → { total, subs, collab, rank, inBoard }`，无 DOM、无存储、无随机、无时间依赖。
- `clamp` + `Number.isFinite` **在引擎入口统一做**；非法值回落 **`n = 420`、`f = 0.52`**（= §3.4 初值，不是 §10 E3 的浇铸回落值）。
- 数字格式化统一（`Intl.NumberFormat('zh-CN')` 或等价），不在模板字符串里散写 `toFixed`。
- `t` 为 0 或负 → 视为非法，回落 `t = 600`（走强制结算分支），**不得产生 `Infinity` 分**。

### 7.4 「不动手」的合法性（`§10 E4` 的对齐）

滑杆初值（§3.4）两个参数都偏离窗口，**不调整直接点「开始车削」是合法的**，落点如下 ——
这条同时是 §8 的 U3 算例①：

```
n = 420, f = 0.52, t = 3.6 s（= 动画时长，未调整参数）
表面质量 = 100 − [min(40,(560−420)×0.35)=40] − [min(45,(0.52−0.40)×120)=14.4] = 45.6
尺寸精度 = n×f = 218.4 ∈ [112,304] → 100
用时得分 = clamp(round(50/3.6×100)) = clamp(1389) = 100
总分 = 45.6×0.45 + 100×0.35 + 100×0.20 = 20.52 + 35 + 20 = 75.52 → 显示 76
入榜 = 否（t = 3.6 s < 10 s 门槛）
```

→ **76 分，不入榜**，与浇铸「不动手 72 分」同量级。**合理。**

⚠️ 若照画稿把初值写成 `620 / 0.32`，同一路径会得到 **100 分** —— 这就是 §3.4 存在的原因。

### U3 的四组算例（**必须逐位一致**）

| # | `n` | `f` | `t` | 表面 | 尺寸 | 用时 | **总分** | 协作分 | 入榜 |
|---|---|---|---|---|---|---|---|---|---|
| ① | 420 | 0.52 | 3.6 s | 45.6 | 100 | 100 | **76** | 见下① | 否 |
| ② | 660 | 0.30 | 50 s | 100 | 100 | 100 | **100** | 100 | 是 |
| ③ | 660 | 0.30 | 90 s | 100 | 100 | 56 | **91** | 100 | 是 |
| ④ | 1200 | 0.80 | 600 s | 25.0 | 65.0 | 8 | **36** | 见下④ | 是（强制结算） |

- ①②③④ 的 `总分 = round(表面×0.45 + 尺寸×0.35 + 用时×0.20)`，**取整只在最后一步**。
- **协作分算例统一假设「累计时间差 = 0」**（即两次参数调整同时发生）；时间差惩罚单独在 U5 验。
- ④ 的 `表面质量 = 100 − 30 − 45 = 25`：`n = 1200 > 760` 走**磨损颤振**分支（系数 0.30 / 上限 30），
  **不是**积屑瘤分支（0.35 / 上限 40）—— 两个分支互斥，别取错。`f = 0.80` 再扣满 45。
- ① 协作分：`|0.52−0.30|/0.10×20 = 44 → min(40, 44) = 40`，`|420−660|/100×20 = 48 → 40`，合计 80 → 协作分 **20**。
- ④ 协作分：`|0.80−0.30|/0.10×20 = 100 → 40`，`|1200−660|/100×20 = 108 → 40`，合计 80 → 协作分 **20**。
- ② 协作分：两项偏差均为 0 → **100**。
- ③ 与 ② 参数相同 → 协作分同为 **100**。
- `E15`（显示取整不"凑数"）**同样适用**：总分与子项各自独立取整。
