## §2 W1 · 地面（三页统一）

### 2.1 诊断（为什么读作"破破烂烂"）

现实现 `makeFloorRoughnessMap()` 做了三件事，**三件都在制造廉价感**：

| # | 现做法 | 后果 |
|---|---|---|
| 1 | 14 个**随机位置**的深色径向斑（`alpha 0.85`，中心比基底暗 60–110/255） | 贴图 `repeat(4,6)` → 全场最多 **336 个互不相关的小黑斑**。这是"脏乱"感的第一来源：**随机 + 小尺度 + 高对比 = 廉价** |
| 2 | 逐像素噪点 `±13/255` | 512 贴图铺 10 m → 噪点尺度 ≈ 2 cm，**比肉眼能分辨的地面颗粒还细**，读作"噪声 / 彩噪"而不是"颗粒" |
| 3 | cast 小场景**沿用了 (4,6)** | 地面是 40×34，却按 40×60 的配方铺 → 单块 **10 m × 5.67 m**，**各向异性拉伸** → 斑块被拉成斜向条带（截图里那些斜纹就是它） |

再叠加两个雪上加霜的：

| # | 现做法 | 后果 |
|---|---|---|
| 4 | `roughness 0.92 / metalness 0.02` | 完全哑光。炉火/铁水在地面上**没有倒影** —— 而这是铸造车间最好看的一帧 |
| 5 | `key.shadow.bias = -0.0006`，阴影相机 68 m 覆盖、`mapSize 1024` | 1024/68 m ≈ 6.6 cm/texel，大平面必然 shadow acne → **地面上的斜向明暗齿纹** |

### 2.2 设计：浇铸车间地坪

**一句话**：地面是一块**规整的铸铁/钢板地坪**。它**均匀**，唯一的非均匀是（a）规则的板缝、（b）三处**成片、低对比、位置固定**的长期磨损、（c）热源附近由光照产生的暖色光池。

> **铁律：脏必须有理由、成片、低对比。随机小斑 + 高频噪点一律不许出现。**

### 2.3 三页参数表（**数值即规格**）

| 场景 | 地面尺寸 | 位置 | 基色 | `roughness` | `metalness` | 板块 | `repeat` |
|---|---|---|---|---|---|---|---|
| 铸造馆 `#/hall` | `PlaneGeometry(40, 60)` | `(0,0,0)` | **`0x23282F`** | **0.42** | **0.22** | 5.0 m | **(8, 12)** |
| 序厅 `#/entrance` | `PlaneGeometry(60, 60)` | `(0,0,0)` | **`0x171C23`** | **0.40** | **0.24** | 5.0 m | **(12, 12)** |
| 浇铸小场景 `#/cast` | `PlaneGeometry(44, 40)` | **`(4, 0, 0)`** | **`0x23282F`** | **0.42** | **0.22** | 5.0 m | **(9, 8)** |

> **`repeat` 必须由尺寸算出来，不许写死。** 公式：`repeat = (W / 5.0, D / 5.0)`，四舍五入到整数。
> 验收：**任取一页，地面上相邻两条板缝的屏幕间距在画幅内应当大致相等**（各向同性）。
> ⚠️ 浇铸小场景的地面由 40×34 `(6,0,2)` 改为 **44×40 `(4,0,0)`** —— 现在它**盖不住冲天炉**（见 Q3.3）。

### 2.4 板缝：用几何画，不用贴图

**为什么不用贴图**：缝需要**颜色**差异（不只是粗糙度），而加一张 `map` 会让贴图数 +1，撞 `V7.textures ≤ 5` 门禁。

**做法**：每个场景加 **1 个合并 mesh**（`+1 draw call`），把板缝画成贴地薄片。

| 项 | 值 |
|---|---|
| 缝宽 | **0.06 m** |
| 颜色 | **`0x161A20`**（比基色暗 ≈20%） |
| 材质 | `MeshBasicMaterial({ color: 0x161A20, transparent: true, opacity: 0.85, depthWrite: false })`，`renderOrder = 1` |
| 高度 | `y = 0.006`（**不得为 0**，否则与地面 z-fighting） |
| 构造 | 沿 x 方向 `W/5 + 1` 条、沿 z 方向 `D/5 + 1` 条，每条 `PlaneGeometry(0.06, 全长)`，全部 merge 进 1 个 mesh |
| 三角面 | 铸造馆 9+13=22 片 × 2 = **44 tri**；序厅 13+13=26 片 = **52 tri** |

> **draw call 账（序厅最紧，`E4a.calls ≤ 14`）**：见 §2.7 的合并方案 —— 板缝 + 炉前构件合并后序厅**仍是 11**。

### 2.5 `makeFloorRoughnessMap` 重写

**签名改为**：

```js
export function makeFloorRoughnessMap({ size = 512, plates = 1 } = {})
```

- `plates` 恒为 1（1 张贴图 = 1 块板），保留参数是为了将来要"1 tile = N 板"时不改调用方。
- `repeat` **不再在函数里写死**，改由调用方按 §2.3 设置。

**贴图内容（只有三层，且全部服从铁律）**：

| 层 | 值 | 说明 |
|---|---|---|
| 基底 | `0.42` → 灰阶 **107** | 与 `material.roughness` 配合：**材质 `roughness` 设为 `1.0`，真实粗糙度由贴图给**（否则两者相乘会得到 0.18 这种不像铸铁的值） |
| 板边倒角 | 距边 `0.10 m`（10 px）内线性升到 **`0.58`（148）** | 板缘比板面略糙 —— 读作"轧制板边"，也让板缝在**粗糙度**上也有痕迹 |
| 低频斑驳 | `±0.06`（**±15 灰阶**） | 周期 ≥ 0.4 板宽，**每块板最多 1 处** |
| 高频噪点 | **`±4`（原 ±13）**，且**先在 256² 生成再放大 2×** | 2 cm 颗粒 → 4 cm 颗粒，读作"颗粒"而不是"彩噪" |
| 大范围磨损 | **只 3 处**，半径 **≥ 1.5 板宽（7.5 m）**，`alpha ≤ 0.12`，**位置固定**（用坐标常量，不用随机） | 沿作业通道分布；**这是"脏"的唯一出口** |

- **禁止**：随机位置的小斑（原 §33 行的 14 个循环整段删除）。
- **禁止**：`Math.random()`（沿用本项目 sin 哈希纪律）。

### 2.6 阴影修复（消除斜向齿纹）

`workshop.js` 的 `key`（`DirectionalLight`，`castShadow`）：

|---|---|---|
| `shadow.bias` | `-0.0006` | **`-0.0002`** |
| `shadow.normalBias` | 无 | **`0.035`**（← 关键，平面 acne 的正解） |
| `shadow.mapSize` | `1024` | **`2048`**（**不增加贴图张数**，只增大尺寸） |

### 2.7 附件：警示线贴图去重（推荐，顺带减贴图数）

现实现为**每一段**警示线 `hazardTex.clone()` → 6 段 = **6 张独立贴图**。

**改法**：6 段共用 **1 张** `hazardTex`，各段的重复次数改由**缩放几何的 UV** 实现：

```js
const geo = new THREE.PlaneGeometry(0.28, len);
const uv = geo.attributes.uv;
for (let i = 0; i < uv.count; i++) uv.setX(i, uv.getX(i) * Math.round(len / 0.5));
// 共用 hazardTex（repeat 保持 1,1）
```

- 收益：**贴图数 −5**（给 W1/W2 的其它调整留出余量），视觉完全不变。
- 若时间紧可跳过，但**必须记录**改后的 `renderer.info.memory.textures` 实测值。

## §3 W2 · 序厅《炉前》建模细化

**前提：`ENTRANCE-FURNACE-SPEC §2` 的坐标一个都不动**（E1a–E1f / E2b 判据全部保持）。本节的改动**全部是"贴皮与构件"，不是"挪东西"**。

诊断（来自 `entrance-wide` / `entrance-furnace` 两张实拍）：**整个序厅是一堆平板拼起来的**——炉壁是一张平板、炉膛是一个黑色矩形、炉床是一个亮色台阶、铁水沟是一条发光胶带、钢构是一片方管栅栏。

### Q2.1 炉膛要有纵深（**最高性价比的一项**）

| 现实现 | 改后 |
|---|---|
| 腔体 `MeshStandardMaterial({ color: 0x1A0E08, roughness: 0.85, metalness: 0.05, side: BackSide })` | **`color: 0x3A2318`，`roughness: 0.9`，`metalness: 0`**，`side: BackSide` 与几何**全部不动** |

- **为什么这么改**：`0x1A0E08` 的线性反照率 ≈0.008，`furnace_core` 点光在腔壁上**画不出任何渐变**（这就是实现方 E5 §4.3 里证明过的同一个物理事实）。抬到 `0x3A2318` 后，腔底受光、腔顶背光，**透过拱口就能看见一道上下渐变**——纵深由此而来。
- **加耐火砖内衬**：腔体**后壁**前 0.10 m（`z = −19.50`）贴 **24 条横向砖缝**：`PlaneGeometry(12, 0.05)`，`y` 从 `1.60` 起**每 0.38 m 一条**，暗 `12%`（`0x32200F`）。24 × 2 tri = **48 tri**。
- 腔侧壁 / 腔顶**不加东西** —— 让光去区分它们。

### Q2.2 炉床 → 熔池（去掉"台阶感"）

**现问题**：两片矩形 `PlaneGeometry` → 外层 `0xC2542F` 铺满、内层 `0xFFC98A` 偏 z 摆放 → 形成**一个边界笔直的亮色梯形**，读作"台阶 / 台座"，不是液体。

**改法**：把"两片矩形"换成"**一片径向渐变的椭圆池 + 一圈池沿**"。

| 件 | 几何 | 位置 | 颜色 | 材质 |
|---|---|---|---|---|
| **液面** | `CircleGeometry(5.6, 32)`，`scale(1, 1, 0.90)`，`rotateX(-π/2)` | `(0, 1.35, −17.1)` | **顶点色径向**：`r/5.6 = 0 → 0xFFE7C0`；`0.55 → 0xE8663C`；`1.0 → 0x8E3418` | `MeshBasicMaterial({ vertexColors: true, side: DoubleSide })` |
| **池沿** | 4 段 `BoxGeometry` 围一圈（宽 0.60、高 0.35） | `y 1.35…1.70`，外沿 `x ±6.0 / z −19.6…−14.6` | `0x2A1A12` | `MeshStandardMaterial({ roughness: .9, metalness: .05 })` |

- **池沿的作用是"盛住"**：0.35 m 高的沿口切掉液面外缘一圈 → 液体**在容器里**，而不是"地上一片橙"。
- ⚠️ **E5① 亮度必须保住**：`E5_PROBES` 的 ① 区 5 个点（`x ±3`、`z −15.6 / −16.8 / −17.6`）距池心 **≤3.1 m（= 半径的 0.55 倍）**。
  → **硬约束：`r/5.6 ≤ 0.60` 的范围内，顶点色不得低于 `0xFFC98A` 的亮度**（即渐变在 r ≤ 3.4 m 内保持"平顶"，3.4 m 之后才开始衰减）。
  → 违背即 `E5①` 由 207.0 掉到 200 以下，判 E5 失败。
- 池沿与液面的净距：液面 `y 1.35`、沿顶 `y 1.70` → **液面始终低于沿顶 0.35 m**（不得溢出）。

### Q2.3 飘火 → 火星（去掉方块）

**现问题**：`PointsMaterial` 的默认点是**方块**。`furnace` 机位距墙 14.24 m，画幅高 14.58 m，`size 0.14` → **屏幕上约 8.6 px 的方块**（实拍里那些黄方块就是它）。规格 §2.8 当初写的"此尺度下方形即读作火星"是**按 `default` 机位（34 m）算的**，`furnace` 机位下不成立。

**改法**：`PointsMaterial` → **`ShaderMaterial`（圆形软遮罩，零贴图）**。

```glsl
// vertex
attribute float aSize;
varying float vFade;
void main() {
  vec4 mv = modelViewMatrix * vec4(position, 1.0);
  gl_PointSize = aSize * 300.0 / -mv.z;    // sizeAttenuation 手写版
  gl_Position = projectionMatrix * mv;
  vFade = clamp(1.0 - (-mv.z) / 30.0, 0.15, 1.0);
}
// fragment
varying float vFade;
uniform vec3 uColor;      // 0xFFB86B
uniform float uOpacity;
void main() {
  float r = length(gl_PointCoord - 0.5) * 2.0;
  if (r > 1.0) discard;                                   // ← 圆
  float soft = smoothstep(1.0, 0.15, r);                  // 软边
  float core = smoothstep(0.55, 0.0, r);                  // 中心热核
  gl_FragColor = vec4(uColor * (0.65 + 0.75 * core), soft * uOpacity * vFade);
}
```

| 参数 | 新值 |
|---|---|
| 数量 `EMBER_N` | **180 → 140** |
| 尺寸 `aSize` | **0.06 … 0.13**，逐粒子由 `rnd(i + 7000)` 决定（**不再是统一 0.14**） |
| 出生盒 `x` | **±7 → ±5.6**（＝炉口净宽半值，让飘火**从炉口里出来**，不再浮在实心炉壁上） |
| 出生盒 `y` | `1.2 … 8.0`（原到 10，会飘到拱顶以上） |
| 出生盒 `z` | `−13.8 … +2.0`（原 −13.6…+3） |
| 混合 / 深度 | `AdditiveBlending` / `depthWrite: false` / `frustumCulled: false`（全部保持） |
| `blending` 下的透明度 | 由 `uOpacity` 控制，呼吸沿用 §4 公式 |

### Q3.5 浇注动画（五段，**总 3400 ms**）

**现问题**：按下「开始浇注」后**什么也没发生** —— 只有砂箱抬起来开箱。**一个叫「亲手浇铸」的互动，没有浇注动作。**

在**同一条 `update(t)` 时间线**上补四段（帧差上限 50 ms 与 `E10` 纪律**保持**）：

| 段 | 时间 | 内容 |
|---|---|---|
| **A 就位** | `0 – 700` | 浇包从休息位 `(4.2, 2.85, 8.2)` 移到**目标箱正上方**（`boxCenter + 0.85 m` 高 2.55 m）。`easeInOutCubic`；路径带 **0.45 m 的抬升弧**（中途 y 最高 3.30）；熔面随移动**轻微晃动**（`±3°`） |
| **B 倾包** | `700 – 1250` | `rotation` 从 0 → **52°**（绕指向箱心的水平轴）；**铁水流出现**：`CylinderGeometry(0.045, 0.07, 1, 10)` 单位高沿 y 缩放，顶接浇嘴、底落**浇口盆**；截面半径由 0.04 → 0.075 |
| **C 充型** | `1250 – 2200` | 流稳定；**落点火花**（复用现有 110 粒子的管线，改在落点生成）；目标砂箱 `instanceColor` 叠加暖色（`1.25, 1.05, 0.80`）；箱体**轻微震动** `±0.008 m @ 12 Hz` |
| **D 收流离开** | `2200 – 2700` | 倾角回 0；流**变细到 0.02 后消失**；火花衰减到 0；浇包返回 `y 3.30` 并水平退回休息位 |
| **E 开箱** | `2700 – 3400` | **复用现有开箱**：上箱抬升 `1.15 m`（`easeOutCubic`）+ 型砂粒子 + 铸件出现；**铸件同时开始冷却**（见 Q3.6） |

- **动作一律走同一条 `update()`**，仍由 `cast.js` 的步骤机驱动；`goStep(3)`（"铁水充型中"）**覆盖 A–D 段**，`goStep(4)` 在 E 段结束回调里触发（**沿用现有 `onDone` 链路**）。
- **`finishOpen()`（「跳过」按钮）** → `progress = TOTAL`，**一次落到 E 段末尾**（含冷却终态）。
- **`prefers-reduced-motion`** → 跳过 A–D，直接 E 段静态落位。
- **`resetBoxes()`（另取一箱 / 重试）** → 浇包回休息位、倾角归零、流与火花隐藏、铸件隐藏。
- ⚠️ **铁水流的可变高度必须用 `mesh.scale.y` 而不是重建几何**（`E4` 性能纪律）。
- ⚠️ **不得使用 `Math.random()`**（火花位置沿用 sin 哈希）。

### Q3.6 铸件：形体 + 冷却动画

| 项 | 原 | 新 |
|---|---|---|
| 形体 | `Box(1.3, 0.36, 0.95)` | **本体** `Box(1.15, 0.30, 0.85)` + **凸台** `Cylinder(0.22, 0.22, 0.12)` + **加强肋** `Box(0.08, 0.26, 0.82)` ×2 + **浇冒口残根** `Cylinder(0.07, 0.07, 0.16)`，merge 1 mesh |
| 缺陷贴图 | `makeIngotTexture`（**保持**） | 保持（气孔 / 冷隔 / 胀砂三档） |
| **冷却（新增）** | 无 | `emissive = 0xFF6A2A`，`emissiveIntensity` 从 **1.15 → 0**，时长 **2500 ms**，`easeOutCubic`，起始于 E 段铸件出现时；**若步骤 ⑤ 已进入，冷却继续在后台跑完** |

- 冷却的叙事价值：**「铁水变成了一件东西」** —— 这是四层体验里唯一能被看见的"凝固"。
- 冷却结束后 `emissiveIntensity = 0`，只剩 `color 0x8A9099 / metalness 0.72` 的金属件 + 缺陷贴图。
