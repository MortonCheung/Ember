# 道具细节补强清单（Step 2B）—— 从「尺寸对」到「像」

> **状态**：待实现方接入。优先级**高于** Step 3（Step 3 的浇铸模块要复用这台车床的观感）。
> **触发**：设计方在复审截图时发现，C620-1 车床的剪影被读成了"火车"。
> **结论**：几何尺寸全部对规格，但**没有一件"能让人认出它是车床"的特征件**。

## 0. 先说清楚这是谁的问题

**是设计方的规格缺陷，不是实现方执行不到位。**

`SCENE-ASSETS-STEP2.md` §2.4 那张表给了 6 个尺寸（床身/主轴箱/尾座/溜板箱/丝杠/卡盘）——
实现方**逐字照做，一个数都没错**。问题是：**只要这 6 个盒子，做出来必然是一列火车。**

```
床身 = 车厢  ·  卡盘 = 车轮  ·  尾座 = 司机室  ·  两条铁轨 = 导轨
```

清单里从头到尾**没有一个字**提到工件、刀架、手轮、手柄、铭牌——
也就是一台车床真正的"脸"。这是清单的疏漏，不是实现方的理解问题。

**顺带一提，这已经是同一类问题的第 4 次**：

| # | 缺陷 | 类型 |
|---|---|---|
| P1 | 灯光强度值与 SPEC §6.4 矛盾 | 数值给错 |
| P2 | 漏写"金属必须有环境贴图" | 机制没写 |
| §4.1 | 引用了 three r163 才有的 API（项目锁 0.160） | 版本没核 |
| **本次** | **给了尺寸，没给"可辨认特征"** | **判据缺失** |

共同点：**规格写的是"参数正确"，而不是"看起来对"。** 本次一并做流程修正（见 §1.3）。

### 1.1 剪影测试（本次新增的硬判据）

> 把道具的所有材质换成纯黑，缩到**高度 128 px**，放到白底上。
> 找 3 个没看过场景的人各看 2 秒，问"这是什么"。
> **≥ 2 人答出"车床 / 机床" → 通过；答"火车 / 桌子 / 柜子 / 箱子" → 不通过。**

为什么用剪影：颜色、材质、光照、环境贴图都会骗人，**只有轮廓不会**。
一个道具像不像，几乎全部由剪影决定；表面细节只是锦上添花。

**为让这个测试可复现**，请给 `?debug=1` 调试钩子加一个方法（实现方自定实现，建议 6 行以内）：

```js
__hall.silhouette(true)   // 全场景材质临时换成纯黑 MeshBasic，背景换纯白
__hall.silhouette(false)  // 还原
```

有了它，`shot_hall.py` 就能直接出剪影图送审 —— 这个判据以后对每个道具都能用。

### 1.2 三条位置关系自检（机械类道具专用）

尺寸对 ≠ 关系对。机械道具必须额外自检这三条，任一不过就是穿帮：

| 自检项 | 规则 | 本道具现状 |
|---|---|---|
| **共轴** | 主轴中心 = 卡盘中心 = 工件中心 = 尾座套筒中心，必须在同一水平线上 | ⚠️ **现尾座轴线 y≈1.55，卡盘轴线 y=1.85 —— 不同心，穿帮** |
| **中心高** | 刀尖必须落在工件轴线上（y = 1.85），否则"刀在切空气" | ⚠️ 目前**没有刀** |
| **接地** | 道具的最低点必须落在 y=0，不能悬空 | ✅ 床腿已处理 |

### 1.3 规格模板修订（流程修正，即刻生效）

`SCENE-ASSETS-STEP2.md` 的道具表**每行增补一列「可辨认特征」**，只写尺寸的表不再算完整规格。

```diff
  | 项 | 场景表现 |
  + | 项 | 场景表现 | 可辨认特征（这一项是为了让人认出什么） |
```

含"可辨认特征"列的道具，才允许进入实现。本文档即按新模板书写，作为范例。

## 2. C620-1 细节补强（本次重点）

坐标系：`museum/exhibits/lathe.js` 的**局部坐标**（group 原点在 `(-14, 0, -25)`）。
现有几何：床身 y 0.7–1.3、主轴箱 x −1.6~−0.7 / y 1.3–2.4、卡盘 x −1.84~−1.60 轴线 y=1.85。

### 2.1 必加六项（这六项直接改剪影，缺一项剪影测试就过不了）

| # | 特征件 | 建议几何 | 为什么它能"救活"这台机器 |
|---|---|---|---|
| 1 | **工件**（卡盘里夹一根料） | `Cylinder(0.085, 0.085, 0.5, 12)`，轴 X，中心 `(-1.45, 1.85, 0)` → 从卡盘端面伸出 0.4 m | 一根突出的圆柱 + 一个夹持它的卡盘，**两个元素一组合，"车床"的语义立刻成立**。单项收益最大 |
| 2 | **方刀台 + 刀头** | 台体 `Box(0.3, 0.3, 0.34)` @ `(0.1, 1.85, 0)`；刀头 `Box(0.14, 0.07, 0.07)` @ `(-0.06, 1.86, 0)`，朝向 −X 指工件 | 有件、有刀、刀对着件 —— 这是"正在车削"的完整句子。**刀尖务必落在 y=1.85 中心高** |
| 3 | **手轮 ×3 + 摇把** | 盘 `Cylinder(0.13/0.10/0.09, ·, 0.05~0.06, 12~16)`：大溜板前 `(0.1, 1.5, 0.32)` 面朝 +Z；尾座右端 `(1.68, 1.85, 0)` 面朝 +X；丝杠右端 `(1.4, 1.35, 0.47)` 面朝 +Z。每个轮偏置一根 `Box(0.035,0.035,0.16)` 摇把 | **手轮是机床类道具的"指纹"**：火车、柜子、桌子都不会在正面长三个摇把。这一项是"去火车化"的关键 |
| 4 | **尾座套筒 + 顶尖**（并修正同心） | 套筒 `Cylinder(0.04, 0.04, 0.45, 10)` 轴 X @ `(0.85, **1.85**, 0)`，从尾座左端面伸出 0.375 m；顶尖 `Cylinder(0.05, 0.01, 0.08, 8)` @ `(0.60, 1.85, 0)` | 与工件对顶，做出"一头夹一头顶"的标准装夹姿态。**同时修掉 §1.2 的共轴错误** |
| 5 | **主轴箱顶部罩壳**（皮带罩/挂轮罩） | `Box(0.75, 0.3, 0.92)` @ `(-1.15, 2.55, 0)` + `Box(0.6, 0.16, 0.8)` @ `(-1.05, 2.78, 0)` | 左上角多出一个"鼓包"，**剪影不再是一条平直的床身线** —— 火车客车没有这个轮廓 |
| 6 | **冷却液托盘** | `Box(3.36, 0.08, 1.4)` @ `(0, 0.66, 0.05)`，比床身（1.1）宽出一圈 | 床身下沿多一圈"盘沿"，机器从"盒子浮着"变成"盒子坐在盘里"，同时解决接地观感 |

### 2.2 建议加五项（操作面细节，不改剪影但显著提升"真实度"）

| # | 特征件 | 建议几何 |
|---|---|---|
| 7 | 变速手柄 ×4 + 开关盒 | 主轴箱正面（z=+0.5）：4 组 `Cylinder(0.035,0.035,0.14,8)` 轴 Z @ x=−1.45/−1.25/−1.05，y=1.5/1.75/2.0/2.2，各带 `Sphere(0.055, 8, 4)` 球头；开关盒 `Box(0.18, 0.22, 0.1)` @ `(-0.78, 2.15, 0.55)` |
| 8 | **铭牌** | `Box(0.42, 0.14, 0.02)` @ `(-1.2, 2.3, 0.515)`，浅色 `#C9D2DA`（需第 3 个材质 → +1 draw call）。**建议只做两道横向细线示意字，不要真渲染汉字**（该尺寸下必糊）—— 它是叙事的钩子（1955 沈阳第一机床厂），不是给人读的 |

### 2.3 顺手修掉的关系错误

**尾座与主轴不同心**（§1.2 第一条）。现状：尾座体 y 1.3–1.8，轴线在 1.55；卡盘轴线在 1.85。
两者相差 0.3 m，等于"顶尖顶在工件下方 30 cm 处"。

修法二选一：

- **A（推荐）**：把尾座抬到套筒轴线 = 1.85。尾座体改为整体高 0.9（y 1.3→2.2），
  或分体：底座 `Box(0.6,0.35,0.6)` @ `(1.3,1.475,0)` + 上部 `Box(0.55,0.5,0.55)` @ `(1.3,1.9,0)`
- **B**：保持尾座高度，把整个主轴箱/卡盘降到 1.55 —— **不推荐**，会破坏已验收的床身高度比例

## 实现说明（代码实现方 · 2026-09-15 18:58）

### 做了什么

- **必加六项（§2.1）全部落地**：①工件（伸出卡盘 0.4m）②方刀台+刀头（刀尖盒中心 y=1.86≈中心高）③手轮×3+摇把（大溜板/尾座/丝杠端，尾座轮加轮毂轴连接）④尾座分体抬升（§2.3 修法 A，套筒轴线=1.85 与卡盘同心）+套筒+顶尖 ⑤主轴箱顶部两级罩壳 ⑥冷却液托盘（床腿相应收到 h=0.62，托盘坐在腿上）
- **建议五项（§2.2）全部落地**：变速手柄×4+球头+开关盒 / 铭牌（Canvas 贴图两道细线示意字，单独第 3 mesh）/ 光杠+开合螺母手柄 / 电机+皮带轮 / 卡盘爪两级台阶
- **剪影钩子**：`__hall.silhouette(on, isolate=true)`，纯黑 MeshBasic + 白底 + 关雾；`isolate=true` 时隐藏车床以外的 mesh（见偏离①）；`silhouette(false)` 完整还原（材质/可见性/背景/雾）。`shot_hall.py` 加 `--sil` 直出剪影图。

### 偏离规格之处（及原因）

1. **光杠 z 0.45 → 0.62**：规格给的 (0, 1.14, 0.45) 落在床身体内（床身 z −0.55~0.55），装进去完全看不见；沿 z 外移到床身前表面外，y 保持 1.14。
2. **补电机座**：规格给的电机底面 y=0.725 悬空，加一只座（0.5×0.73×0.55）落到 y=0，保住"接地"自检。
3. **床腿高度 1.0 → 0.62**：托盘底面 y=0.62，原床腿穿过托盘；收到 0.62 后"腿-盘-床身"三层堆叠干净，接地不变。
4. **剪影钩子默认 isolate**：字面的"全场景换纯黑"会让黑色地面/墙面吃掉剪影，测试没法判；默认只留车床本体，需要字面行为时 `silhouette(true, false)`。
