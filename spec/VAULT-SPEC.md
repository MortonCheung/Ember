## §1 页面结构与尺寸

整屏 1440×900，**横向两栏，无 HUD、无场馆导航**（画稿如此 —— 这是"抵达终点"的静止页，不是展厅）。
出口由右下按钮行承担（§10）。

| 栏 | 宽 | padding | 内容 |
|---|---|---|---|
| 左栏 · 藏品展示 | **620**（固定） | 56 | 藏品卡（400×560，**水平居中**）+ **馆藏图鉴带**（规格新增，§4） |
| 右栏 · 功能与衍生 | `fill`（= 820） | 56 | 眉标 / 标题 / 正文 / 衍生品宫格 / 按钮行 |

**左栏高度核算**（必须成立，否则 §4 会被挤掉）：
`56 + 560(卡) + 22(gap) + 20(图鉴标题行) + 164(图鉴 2×78 + gap 8) + 56 = 878 ≤ 900` ✓（余 22px）

> 画布实测（`capture_layout`，2026-09-21）：`3:240` 藏品卡 = **400×560 @ (110, 4970)**、
> 左栏内容宽 `620 − 56×2 = 508` ✓、右栏宫格 `3:264` = **708×316 @ (676, 5128)** —— 与上面核算一致。

> 兜底：若实现在 375px 或浏览器字体差异下溢出，**优先压缩「卡 ↔ 图鉴」的 gap（22 → 16）**，
> **不要缩藏品卡**（400×560 是画稿定值）。

## §3 徽记区（**规格新增** —— 画稿此格是一张 688×420 的灰色占位图 `3:244`）

画布阶段拿不到真实产出，画稿用灰占位。**这里定义它是什么。**

### 3.1 它是什么

**一枚圆形铸造徽记**，由三部分组成 —— 全部由**已解锁数据**决定，**零随机**：

| 层 | 内容 | 数据来源 |
|---|---|---|
| 外圈 | **12 格刻度环**（12 段等分圆弧，段间留 2° 缝）：已解锁段 `--c-iron`，未解锁段 `--c-line` | `unlocked` 数组（§9） |
| 环内 | **铸件轮廓**：4 种之一 —— `法兰` / `床身` / `阀体` / `齿轮`（简笔线稿） | 见 §3.3 |
| 底环 | 一圈**等距刻度短线**（36 根，`--c-line` 40% 透明）—— 工业仪表感，纯装饰但确定 | 固定 |

### 3.2 画在哪：**用 `<canvas>`，不用 SVG**

**理由（重要，决定了分享海报能不能做）**：`§8` 的分享海报要用 Canvas 2D 重绘整张卡。
如果徽记是 SVG，就要维护两套绘制代码 —— 迟早不一致。

**裁定：徽记用 `<canvas>` 绘制，绘制函数抽成 `drawEmblem(ctx, x, y, size, data)`，
页面上与海报上调用同一个函数。** 尺寸按 `devicePixelRatio` 缩放，避免模糊。

### 3.3 铸件轮廓怎么选（确定、可复现、零新增存储）

取 **`unlocked` 数组中序号最小的砂箱** → 查 `STEP3 §3.2` 表得它的**铸件类型** → 用对应轮廓。

- 例：`unlocked = [8, 4]` → 最小是 `4` → 床身 → 画**床身**轮廓
- 语义：**你最早浇出的那件铸件** —— 有纪念感，且不需要新增任何存储字段
- 4 种轮廓各由 6–10 条线段构成（简笔线稿，`--c-text` 40% 透明描边，不做填充）

### 3.4 空态的画法（`unlocked` 为空时）

- 12 段刻度**全暗**（`--c-line`）
- 环内不画铸件轮廓，画**一个未点火的炉口拱形轮廓**（同 `S10` 的炉口剪影简化版，`--c-steel`）
- 中央一行 11px `--c-steel`：`尚未点火`

## §5 衍生品宫格与**解锁态**（画稿 4 张全亮 → 补齐锁定态）

`§7` 定了：**≥ 3 件解锁「工牌实体卡」**；**≥ 8 件解锁全部文创文案**。
画稿 S05 把 4 张卡**全部平铺点亮**了 —— 那是 `3 / 12` 状态下的**示意**，不是规则。**必须补锁定态。**

### 5.1 宫格版式（画稿 240 宽 → **裁定改为 2 列铺满**）

**画稿实测的问题**：4 张卡各 240 宽，而右栏内容宽 708 → 只能排 2 列（`2×240 + 16 = 496`），
**右侧空出 212 px（占容器 30%）**；画布实测 `capture_layout` 在 `3:264` 报出这条 `LARGE_EMPTY_AREA`。
而 240 宽排 3 列也不成立（`3×240 + 32 = 752 > 708`）。

**裁定：每张卡宽 `calc((100% − 16px) / 2)`（≈ 346），高 150，圆角 10，`--c-surface`，`padding 18`，`gap 8`**
→ **2 列 × 2 行铺满右栏，无空白**。
卡片变宽后最长说明文案（18 字，11px）单行即可容纳，比画稿更干净。

### 5.2 四件衍生品（文案照画稿，不改）

| # | 名称 | 说明 | 解锁条件 |
|---|---|---|---|
| 1 | `齿轮巧克力` | `以馆藏齿轮为原型，号码即模具编号` | **始终可用**（基础款） |
| 2 | `铁水纹亚克力摆件` | `封存你那一炉的铁水流动瞬间` | **始终可用**（基础款） |
| 3 | `工牌实体卡` | `馆内自助机打印，可挂工装口袋` | **`n ≥ 3`**（`§7`） |
| 4 | `劳模语录卡` | `随机掉落张成哲、吴家柱等劳模语录` | **`n ≥ 8`**（`§7`） |

> ⚠️ 第 4 项画稿文案里的「**随机**掉落」指线下文创的抽取方式，**不是本页的实现要求** ——
> 本页只显示这一句文案，**代码里不得有 `Math.random()`**（项目零随机铁律）。

### 5.3 锁定态

- 名称与说明保持可读但降对比：名称 `--c-text-muted`，说明 `--c-steel`
- 卡片右上角一枚 11px 徽标（**只在锁定态出现**）：`需 3 / 12` / `需 8 / 12`
  （数字是该卡的**门槛**，不是已解锁数）；解锁后**不显示徽标**（此时名称已回到 `--c-text`，徽标失去意义，见上一行）
  > **勘误（2026-09-23 深夜）**：本行原写 `` `已解锁 3/12` / `已解锁 8/12` ``。
  > 「已解锁」+ 门槛数字 = 一句话说反了，与同卡展开说明「需要解锁 3 件馆藏」自相矛盾。
  > 依 `spec/AESTHETIC-AUDIT.md` §6 P0 与 `archive/spec/PROMPT-P0-FIXES.md` FIX-1 改稿
  > （该 FIX 已于 **2026-09-24 实现**，自述 `spec/IMPLEMENTATION-P0-FIXES.md`）。
- **不做毛玻璃、不做锁形图标** —— 用降对比 + 一行小字即可（与场馆导航「· 筹备中」同一手法）

## §7 姓名编辑

`STEP3 §6.2` 写「`name` · 用户输入（**步骤⑤可编辑**）」，但步骤⑤**没有实现姓名输入**（`cast.js` 里 `badge.name ?? ''` 恒为空串）。

**裁定：姓名编辑位置改由本页承担 —— 覆盖 `§6.2` 的「步骤⑤」表述。**

| 项 | 规格 |
|---|---|
| 位置 | 藏品卡的姓名行（§2 第 3 项） |
| 交互 | 点击姓名 → 原地变 `input`（同字号同字重，透明底 + 底部 1px `--c-iron`）；`Enter` 或失焦提交；`Esc` 取消 |
| 约束 | `maxlength 8`；去掉首尾空格；**空串不写入**（保持原值） |
| 写回 | `im.badge.name`（**只改这一个字段**） |
| 空态下 | 姓名行显示 `未署名` + 11px `--c-steel` 提示 `点击填写姓名`，**可编辑**（先于工牌生成也能填） |

> 理由：① 零回归风险（不动已验收的 `cast.js`）；② 语义更自然（先看到工牌，再签上名字）。

## §8 分享海报（主按钮，**不能做成装饰**）

画稿主按钮是 `生成分享海报`。**`STEP3 §6.2` 给的路走不通**：
它写「铸件缩略图（开箱后截帧，`toDataURL` 用 `preserveDrawingBuffer: true` 或离屏重绘）」，
而 `viewport.js` 的渲染器**没有开 `preserveDrawingBuffer`** —— 现在取帧会拿到空图；
打开它又有性能代价，且要求三维场景仍在渲染（离开 `#/cast` 后场景已 dispose）。

**裁定：用 Canvas 2D 重绘一张海报。零依赖、零 WebGL 依赖、确定性、可离线。**

| 项 | 规格 |
|---|---|
| 尺寸 | **1080 × 1350**（4:5，微信 / 小红书友好） |
| 内容 | 底色 `--c-bg` → 徽记（**复用 `drawEmblem()`**，`§3.2`）→ 姓名（64px Bold）→ 工种 · 等级（28px `--c-iron`）→ 三值（40px Inter Bold，横排）→ 编号（24px Inter `--c-steel`）→ 卡头标签 → 底部 `炉火不灭 · 2026` |
| 字体 | 必须 `await document.fonts.ready` 后再绘制，否则中文字形回落 |
| 导出 | `canvas.toBlob(blob => …)` → `URL.createObjectURL` → 动态 `<a download="工牌-NO.000137.png">` 触发下载 → **用后 `URL.revokeObjectURL`** |
| 反馈 | 导出中按钮置 `disabled` + 文案 `生成中…`；完成后恢复并把按钮文案改为 `已导出 ✓`（`reduced-motion` 下无过渡） |
| 空态 | 按钮 `disabled`（§6.1） |
| 零随机 | 同数据 → 同图（可逐像素比对） |

### ⚠️ 两处口径必须修正

1. **`n` 的来源**：现状 `badge.unlocked` 存的是**字符串** `"3/12"`。
   本页的 `n` **一律以 `im.cast.unlocked` 数组长度为准**；

2. **`turnTime` 为 `null` 时**（没玩过车削）：显示 `—`，**不显示 `00:00`**；
   并在右栏下方加一行 11px `--c-steel` 链接：`去协作车削 →`（指向 `#/turn`）。
