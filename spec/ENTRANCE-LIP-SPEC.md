## §0 结论摘要

| 项 | 处置 |
|---|---|
| **根因** | ②③ 采样的**墙面**法线朝观众，而唯一能造光晕的「炉膛内芯」`PointLight` 在墙**背面**的炉膛里（`z −16.5` vs 墙 `z −14.6`）→ 点积为负，**物理不可达**；§8 又把 bloom / 贴图 / `AmbientLight` / 顶点色假辉光全禁掉 |
| **正解** | **在炉口洞内加一圈「收口内衬」** —— 发光几何（`MeshBasicMaterial` + 顶点色），既朝观众可见、亮度又直接可控 |
| **阈值** | **一个都不动**（200 / 140 / 60–140 / 60） |
| **改什么** | 新增 1 个 mesh + **E5 ②③ 的采样口径**（从「墙面」移到「内衬」） |
| **不动的** | 炉口净开口 12.0 × 7.5 · 炉膛净深 5.0 · 光源仍 6(+1) 盏 · 贴图 0 增量 · §8 全部禁令 |

**一句话**：这不是「降低标准」，是**把一个做不到的标准换成同一个视觉目标下做得到的标准**。

## §1 为什么是「修正标准」而不是「降低标准」

规格 §6.2 的 E5 想验的是**「从炉芯向外有肉眼可辨的亮度阶梯」**——这个目标是对的，也是序厅能不能被一眼命名成「炉子」的关键。

问题出在**②③ 把采样放在墙面上**，而墙面在这个场景里**注定是暗的**：

| | ② 采样的墙面 | 炉膛内芯灯 |
|---|---|---|
| 位置 | `z = −14.0`（墙的**观众侧**表面） | `(0, 3.0, −16.5)`（墙**背面**的炉膛里） |
| 法线 | `(0, 0, +1)`（朝观众） | — |
| 结论 | 从采样点指向灯的方向 z 分量为**负** → **背光**，点积 < 0 | 照不到 |

而 §8 的禁令又封死了所有替代手段：
§8.3 禁顶点色假辉光 · §8.4 禁后处理（bloom）· §8.5 禁贴图（含 canvas sprite）· §8.7 禁 `AmbientLight`。

→ 在「炉壁 `0x14171C` + 光预算 6/7 盏」下，② 的天花板就是 ≈30（实测 21.9）。
**这不是反照率低的问题，是朝向问题。**

**更关键的一点**：实测 ② 21.9 **<** ④ 24.0 —— **唇口比墙角还暗**。
所以连「改成相对判据（② > ③ > ④ 单调递减）」都救不了：**分层这件事根本没发生**。

> ⚠️ 设计侧更正：2026-09-18 的内部记录里建议过「改为相对判据」，**该建议作废**。理由即上。

## §2 炉口内衬（`furnace_lip`）几何

**在洞口内部加一圈「朝炉膛收口」的锥面。** 关键：它**同时**朝观众（`N·V ≈ 0.64`，看得见）
和朝炉膛（`N·L > 0`，在光的一侧），且**完全落在洞内，不穿墙**。

### 2.1 参数

| 项 | 值 |
|---|---|
| 观众侧轮廓 | `z = −14.0`（墙前表面），**等于 `HOLE_PATH` 原轮廓** —— 12.0 × 7.5 |
| 炉膛侧轮廓 | `z = −14.6`（墙后表面），**径向收缩 `LIP_INSET = 0.50 m`** |
| 收缩后净开口 | 11.0 × 6.5（`x ±5.5`、`y 1.70…8.20`，拱心 `(0, 5.4)`、`a=5.5`、`b=2.8`） |
| 面倾角 | `atan(0.50 / 0.60) ≈ 39.8°`（相对轴线） |
| 三角面 | 沿轮廓 64 段 × 2 tri = **128 tri** |
| draw call | **+1**（序厅 12 → 13，仍 ≤ E4a 的 14） |

### 2.2 轮廓生成（参数化，**两层必须同参数**）

```
inset(u) = 0.50 * u                    // u = 0 观众侧 → 1 炉膛侧
z(u)     = −14.0 − 0.60 * u
轮廓(u):  底边  y = 1.20 + inset(u)，x ∈ ±(6 − inset(u))
          侧壁  x = ∓(6 − inset(u))，y ∈ [1.20 + inset(u), 5.4]
          拱    中心 (0, 5.4)，a = 6 − inset(u)，b = 3.3 − inset(u)
```

⚠️ **两层点必须一一对应**。禁止对两条不同的 `Path` 各调 `getPoints(64)` —— 曲率分布不同会导致点错位、面扭。
正确做法：自己按段参数化（底边 / 左壁 / 拱 / 右壁各若干段），**内外两层用同一套参数**。

### 2.3 位置与命名

- `mesh.name = 'furnace_lip'`，加进 `entrance_hall` 组
- ⚠️ **不改 `HOLE_PATH`** —— 墙的挖洞仍用它，所以 **E1b 净开口 12.0 × 7.5 一字不变**
- ⚠️ **不遮炉床**：内衬 `z ∈ [−14.6, −14.0]`，炉床在 `z ≤ −14.6` → 无交叠（验收 L4）
- ⚠️ **不遮铁水沟**：沟起点 `[0, 1.18, −13.9]` 在洞口**前方**，内衬底缘 `y ≥ 1.20` → 无交叠

### 2.4 `entranceSilhouette()` 要隐藏内衬

E1″ 盲测的隔离视图语义是「**炉壁纯黑 + 开口纯白**」。内衬属开口区，**必须一并隐藏**，
否则开口里会出现一圈灰面，破坏黑白对比（验收 L9）。

## §3 材质与顶点色

`MeshBasicMaterial({ vertexColors: true, side: THREE.FrontSide })` —— **发光件，不受光**，
与 §2.3 炉床、§2.5 铁水面同一族。**这不是 §8.3 禁止的「顶点色假装炉壁辉光」**：
§8.3 禁的是「在墙面上涂色伪装辉光」，本件是**一圈实体几何**（真实炉衬），与铁水面同理。

### 3.1 顶点色（沿进深 u）

| u | 十六进制 | 含义 | 屏幕 luma（ACES + sRGB 后，**估算**） |
|---|---|---|---|
| 0（观众侧 · 洞口缘） | `0xA8481F` | 渐隐入黑墙 | ≈ 100 |
| 1（炉膛侧 · 最深处） | `0xF08A4A` | 与炉床同源，稍暗 | ≈ 173 |

- 中间线性插值。写法与 `§2.5` 的 `C_RUN_*` 一致：`new THREE.Color(0xA8481F)` 即可
  （r152+ `ColorManagement` 默认开启，`setHex` 自动转 linear）。
- **上色方向**：u=0（洞口缘）暗、u=1（炉膛侧）亮 —— 物理上「越深越热」，视觉上「渐隐入黑墙」。
- ⚠️ **内衬必须比炉床（① ，实测 207）暗** —— ① 仍是画面最亮处。
  `0xF08A4A` 的 luma ≈ 173 < 207 ✓ **顶点色不得超过 `0xFFD9A8`**（那会与炉床抢主角）。

> 上表的 luma 是按 ACESFilmic + sRGB 估算的，**验收以渲染帧实测为准**。
> 若 ② 实测 < 140，**调亮顶点色**（上限 `0xFFD9A8`），**不要动阈值**。

## §7 不要做的事

1. **不要改 E5 的阈值**（200 / 140 / 60–140 / 60）。若实测不足，调**顶点色**。
2. **不要改 `HOLE_PATH`**、不要改炉口净开口。
3. **不要为了提亮内衬而加光源**（§5.2）。
4. **不要给内衬加贴图 / 后处理 / 顶点色列表之外的动态**。
5. **不要让内衬参与 §4 的三项动画**（静态；呼吸只许动炉膛灯 + 炉床色 + 粒子）。
6. **不要把内衬做成发光「圆环」**：它是一圈**朝炉膛收口的锥面**，有进深、有方向，
   不是一个贴在洞口上的平面环（那正是 §8.3 警告的「发光圆环」）。
7. 不要跳过 E1″ 盲测（`ENTRANCE-FURNACE-SPEC` §8.10 明令）。
