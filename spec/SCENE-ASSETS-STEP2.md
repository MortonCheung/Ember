### 4.1 ⚠️ 金属材质必须有环境贴图（否则发黑）

**这是 three.js 的硬性机制**：`MeshStandardMaterial` 的 `metalness` 会把**漫反射**按
`(1 − metalness)` 衰减，而金属的**镜面反射成分完全依赖环境贴图**。
`scene.environment` 为空时，高 metalness 材质拿不到任何反射来源 → **渲染成近黑色剪影**。

本清单中有 12 个材质的 metalness ≥ 0.4（天吊 .6、管道 .6、护栏 .6、导轨 .85、炉身 .55…），
**必须**为场景提供环境贴图：

```js
// 方案 A：three.js 内置房间环境（推荐起步）
import { RoomEnvironment } from 'three/examples/jsm/environments/RoomEnvironment.js';
const pmrem = new THREE.PMREMGenerator(renderer);
const envRT = pmrem.fromScene(new RoomEnvironment(), 0.04);
scene.environment = envRT.texture;
pmrem.dispose();                     // 注意：只释放生成器，envRT 仍有效，卸载时再 envRT.dispose()

// ⚠️ three 0.160 没有 Scene.environmentIntensity（r163 才引入）。
//    写 scene.environmentIntensity = 0.25 既不报错也不生效（静默忽略）——
//    等价做法是逐材质设 envMapIntensity：
const ENV_INTENSITY = 0.25;          // 压低，保持"熄火车间"的暗调
group.traverse((o) => {
  if (!o.isMesh) return;
  const mats = Array.isArray(o.material) ? o.material : [o.material];
  for (const m of mats) if (m?.isMeshStandardMaterial) m.envMapIntensity = ENV_INTENSITY;
});
// 若日后升级到 three ≥ r163，可直接改回 scene.environmentIntensity = 0.25

// 方案 B：自建暗色渐变 + 炉火侧暖斑的环境贴图（更贴合作品基调，成本略高）
```

**若不引入环境贴图，则必须把所有 metalness 降到 ≤ 0.15** —— 但那会丢掉金属质感，不推荐。

> 环境贴图会增加少量着色开销；当前 draw call 仅 32，有余量，无需担心。

**WebGL1 降级**：极低端设备上 PMREM 可能不可用，用 `try/catch` 包住并静默跳过即可 ——
此时金属退化为无反射（发黑），属**可接受的降级**，但绝不能因此中断渲染。降级链中
"WebGL1 无金属质感"应被视为已知且允许的损失。
