### 🔴 P2｜金属材质全黑 —— 缺环境贴图（重要）

**独立核验结果**：`scene.environment === null`，而场景中有 **12 个 metalness ≥ 0.4 的材质**
（`crane_bridge:0.6`、`crane_hook:0.6`、`wall_pipes:0.6`、`cupola_rail:0.6`、`cupola_ladder:0.55`、
`lathe_steel:0.85`、炉身 `0.55`、立柱 `0.5` …）。

**机制**：three.js 的 `MeshStandardMaterial` 中，`metalness` 会把漫反射按 `(1−metalness)` 衰减，
而金属的镜面成分**完全依赖环境贴图**。`scene.environment` 为空 → 高 metalness 材质拿不到任何反射来源
→ **渲染成近黑剪影**。

**这是当前画面偏暗、层次不足的主因**（比 P1 影响更大）。截图可见：天吊、管道、护栏、卡盘、导轨
全部读不出金属质感，只剩黑块。

**修法（约 4 行）**：

```js
import { RoomEnvironment } from 'three/examples/jsm/environments/RoomEnvironment.js';
const pmrem = new THREE.PMREMGenerator(renderer);
scene.environment = pmrem.fromScene(new RoomEnvironment(), 0.04).texture;
scene.environmentIntensity = 0.25;   // 压低，保持"熄火车间"的暗调
```

若不想引入环境贴图，则须把所有 metalness 降到 ≤0.15 —— 但会丢掉金属质感，不推荐。

**已写入** `SCENE-ASSETS-STEP2.md` §4.1（含机制说明与两种方案）。

### 🟡 P3｜炉口光环偏弱（次要）

`TorusGeometry(2.0, **0.09**, 8, 32)`。Step 1 验收版实测调优为 **0.14**（0.09 时"炉火之光"读不出来）。
建议回改 0.12–0.14。

### 🟡 P4｜动态光源 11 盏，低配机有风险（次要）

实测 `lightCount = 11`。前向渲染下每盏灯都会增加所有材质的着色成本。
其中 6 盏吊灯强度仅 0.4、视觉贡献最小，**是削减的首选**。
当前 FPS 240 有余量，不阻塞，但这是 B 档（低配机也要能开）的潜在风险点。

### ⚪ P5｜地面导向线与砂箱区重叠（轻微）

地面橙色导向线在 `x = ±8.8`，而砂箱阵列占 `x 5.2–11.8` —— **导向线从阵列中间穿过**，
与警示线叠在一起，画面略乱。建议导向线绕开阵列，或阵列微调。

### ⚪ P6｜默认机位下砂箱阵列偏画面边缘（轻微）

默认机位里砂箱阵列位于右下角、与 `(13,6)` 立柱视觉上贴近。Step 3 会为浇铸另设机位，
暂不阻塞；若默认机位要调整，建议一并考虑。

- 加一盏 0.06 的极弱 `AmbientLight`，只抬起暗部下限，或
- `setClearColor` / `scene.background` 由 `0x0E1116` 提到 `0x131922`（更冷、更像空厂房）

**三选一，不要同时上** —— 同时上会冲掉炉火作为唯一暖色光源的主导地位，那才是这个作品的视觉定义。
此项等 Step 3 与您确认后再动。
