## 2. 新形态规格（**核心**）

### 2.1 形态基准确认

先打开 `design/S09-序厅形态与光影基准.png`。**雕塑的正面剪影必须与"目标剪影 · 正面"外轮廓对齐**，
它由四段构成，另加分离的空中液滴：

| 段 | 占横向跨度 | 内容 | 为什么必须有 |
|---|---|---|---|
| **① 源头唇口** | 0–15% | 一段略粗的水平承接体，端部收成**唇口**（读作炉口 / 浇包口） | 没有它，物体没有"从哪倒出来"，就只能被读成动物的角 |
| **② 颈缩** | 15–25% | 截面迅速收窄到 ①的 45% —— 液体离口后被拉细的瞬间 | 液体特征；也制造"动势的起点" |
| **③ 主落片** | 25–72% | 由窄到宽向下的**片状**（横向 1.2 m → 5.5 m），底缘带 **3–4 条指状分流** | "倾泻"的主体 |
| **④ 落点飞溅冠** | 72–100% | 低矮的蘑菇状翻卷，左右各一个**回卷尖**；冠的横向宽度 ≥ ③中段厚度的 **2 倍** | 唯一能说"砸在地面上"的东西 |
| **空中液滴** | 散布在 ③④ 上方 | **7 颗**，直径 0.25–0.9 m，**必须与主体分离**（剪影上成独立小块） | "瞬间冻结"的动势；也是液体的确证 |

### 2.2 构造法（**不要再用"多段圆柱接"**）

**推荐：一条连续样条 + 变宽变厚截面，一次性生成整片带子。**

1. `CatmullRomCurve3` 定主带中心线，从 ① 到 ③ 末端。
2. 沿 t **采样 40 点**，每点取切向 `T`；用固定上向量 `(0,1,0)` 求 `N = T × up`、`B = N × T`（**不要用 Frenet，会翻转**）。
3. 每个采样点放 **8 个环点**，围成一个**扁矩形**：宽 `w(t)` × 厚 `h(t)`。
   - `w(t)`：**0.5 m → 5.5 m**，用 `smoothstep` 单调递增（不要线性，线性读作"木梁"）
   - `h(t)`：**0.35 m → 1.6 m**
   - ⚠️ **宽:厚 全程 ≥ 3:1**，这是"管"与"流淌的金属"的分界
4. 按 40×8 索引成面 → **一条连续几何，天生没有段缝**。
5. **分流舌 4 条**：从 t ≈ 0.55 / 0.68 / 0.78 / 0.88 处**分叉**，各自落向地面不同点（横向散开 2–4 m）。同样方法，每条采样 12 点。
6. **落点冠**：主带末端 t=1 处，5 片压扁的 `ConeGeometry`（r 1.2–2.8，h 0.5）向外翻卷 + 1 个低矮 `CylinderGeometry`（r 3.2，h 0.9）作基座。
7. **液滴 7 颗**：`SphereGeometry(0.25–0.9, 8, 6)`，散布在落点上方 3–9 m。
8. 全部 `mergeGeometries` 进 **1 个 mesh**。

**替代实现**（只要 §7 的 E1′ 四查全过）：`ExtrudeGeometry` 沿样条拉伸扁矩形截面后逐顶点缩放。
**不推荐** `TubeGeometry` —— 它默认圆截面，出来还是管。

面数估算：主带 640 + 分流舌 768 + 冠 ≈200 + 液滴 ≈670 ≈ **2,300 三角面**（上限 6,000，余量充足）。

### 2.3 禁止项（**违反即退回**）

1. ❌ **不得用多个独立圆柱 / 棱柱"接"出主带** —— 段缝必然出现。
2. ❌ **不得靠"搭接"遮豁口** —— 搭接产生的是**横向环状台阶（竹节）**，那是廉价 3D 的标志，比豁口更难看。**要消除豁口就消除接缝本身。**
3. ❌ 不得使用圆截面（宽:厚 = 1:1）。
4. ❌ 不得把液滴做成"散落在地上的方块" —— 必须在**空中**、且与主体**分离**。
5. ❌ 不得保留任何**横向**环状棱线。允许的棱只有**沿流向的纵向凸棱**（沿样条走、不闭合成环）。

## 3. 材质

| 项 | 旧值 | **新值** | 理由 |
|---|---|---|---|
| 基色 | `#6B5B4A` | **`#9A7F5C`** | 亮约 40%。暗室里深青铜 = 黑，这是"丑"最大的单一来源 |
| `metalness` | `.8` | **`.85`** | 提高镜面成分 |
| `roughness` | `.35` | **`.26`** | 让高光有形状，不是一片糊 |
| `envMapIntensity` | `.25` | **`.55`** | 序厅只有一件主体，环境反射可以拉高（铸造馆的 .25 是为大场景省预算，**别照抄**） |

> 全站铁水橙纪律不破：**物体上不放橙色**。它是**凝固的**钢水，青铜底色。暖色只由主光与地面光池产生。

## 4. 光照（**"好看"的最大杠杆**）

| 灯 | 参数 | 作用 |
|---|---|---|
| 环境 | `HemisphereLight(0x2A3A4A, 0x14181D, **0.55**)` | 提高底噪，别让暗部死黑 |
| **主光 Key** | `SpotLight(**0xFFF1E2**, **4.5**)`，pos `(4, 16, 10)` → target `(0, 5.4, 0)`，`angle .34`、`penumbra .55`、`decay 1.3`、`distance 52`，**`castShadow = true`** | 塑形；暖色只在这里 |
| **轮廓光 Rim** ⭐ | `SpotLight(**0x8FB4D8**, **3.0**)`，pos `(-6, 12, -9)` → target `(0, 6, 0)`，`angle .5`、`penumbra .7`、`decay 1.2`、`distance 44` | **把主体从暗背景里"切"出来**。这是本轮最关键的一盏灯 |
| 地面光池 | `SpotLight(0xFFE9D6, **1.6**)`，pos `(0, 14, 0)` → target `(0, 0, 0)`，`angle .85`、`penumbra **1.0**`、`decay 1.1`、`distance 30` | 地面一团柔光，让雕塑"落地"、给空间一个底 |
| 补光 | `DirectionalLight(0xFFFFFF, **0.18**)`，pos `(10, 1.5, 9)` | 只救暗部 |

- **冷轮廓 + 暖主光**是雕塑摄影的标准打法，也是"一眼高级"的来源。轮廓光**不可省**。
- 阴影：主光 `castShadow`，`shadow.mapSize 1024`，地面 `receiveShadow = true`，雕塑 `castShadow = true`。
- ⚠️ 仍然**不要写 `Scene.environmentIntensity`**（three r163+ 才有，本项目锁 `^0.160`）。
