## 2. 为什么改

### A. 小地图把工具车压住了 16.2%（**双方都漏了**）
`.minimap` 是 180 × 120 的右下角 DOM 悬浮层，实测矩形 **[1236, 756, 1416, 876]**（`layout.css`：`right/bottom: 24px`）。
默认机位下规格自己给的 `(16.4, 0, −3.0)` 工具车屏幕框是 `[1271, 706, 1335, 766]` ——
**它和面板矩形重叠 64 × 10 px，占工具车屏幕框的 16.2%**：车轮与柜体下部被磨砂面板压住。

"不压 HUD"这条判据，两边都只对着**画幅四边**查了，没查 **HUD 本身**。参照物被面板挡住 = 参照作用打了折，且看着像出错。

设计方做了 272 个网格落位的寻优（约束 = 不压小地图 + 不压车床 + 不出画幅 + 留白），定稿 **(13.0, 0, −2.6)**。
它落在**砂箱阵列屏幕右缘 994 与车床屏幕左缘 1181 之间的空档**里，工具车右缘 1183 与车床左缘 1181 **相接而不相压**。

### B. `hRatio = 0.49±0.03` 是**我的算术错**
0.92 / 1.86 是**世界**高度比，只有在两件东西到相机距离相同、包箱纵深相当时才等于**屏幕**比。实测（同一默认机位，只挪工具车）：

| 落位 | (16.4,−3.0) | (13.0,−2.6) | (13.2,−4.6) | (13.0,−5.6) | (17.6,−6.0) |
|---|---|---|---|---|---|
| `hRatio` | 0.487 | 0.443 | 0.406 | 0.387 | 0.437 |

再叠加 `cart` 近观预设（工具车离相机近 1.85 m）会读到 **0.68** —— 透视放大，物理上正确。
所以固定 0.49 **是在用落位代替尺度**：工具车一移动就会"不过"，必然诱导下一个人去改阈值 —— 正是 R3 要防的事。

**真正证明"参照物是真实尺度"的是世界量本身**（`scale` / `userData.height` / 未旋转包箱），屏幕比降级为**粗筛**。

### C. W2/W6 轴序（**我的规格缺陷**，已修）
你指认属实：W2 写"长/宽/高（x/z/y）"、W6 写 `(1.26, 0.63, 0.98)`（x/y/z），**同一份规格两套次序**。
已在 R3 提示词 §3 开头加**全局轴序约定**：*所有三元尺寸一律按世界轴序 `(x, y, z)` 书写；语义名（长/宽/高）随物件而变，轴序不变*。
**你的处理接受**（按规格次序返回 + 在 `name` 里标注轴序），作为后续交付的默认做法，本轮不用改。

## 3. 做什么（四组）

### ① 工具车落位：`props/toolcart.js` 的 `POS`
```js
const POS = { x: 13.0, z: -2.6 };   // 2C-R4（§10.7-A）：砂箱阵列与车床之间的空档，避开右下小地图
```
- `ROT_Y = 20°` **不变**（与车床同向，仍是操作者侧前方的停放姿态）。
- `scale = (1,1,1)`、`userData.height = 0.92`、几何与材质 **一律不动**。
- 文件头注释补一句：*落位由 `SCENE-LAYOUT-FIX-SPEC.md` §10.7-A 定稿（原 16.4,−3.0 因小地图压占 16.2% 作废）*。
- **允许 ±0.3 m 微调**，但必须同时满足：小地图压占 `= 0`、`latheCovered ≤ 0.10`、`overlapWithLathe ≤ 0.20`、右留白 `≥ 120 px`、下留白 `≥ 100 px`。若有微调，把最终值写进交付说明。

### ② `cart` 预设（`viewport.js` HALL_VIEWS）
```js
cart: { pos: [14.8, 2.0, 2.8], target: [14.3, 0.8, -3.7] },   // 工具车 + 车床同框
```
实测：车床占画幅宽 **38.0%**、工具车 **17.1%**，两件同框、互不相压（`overlapWithLathe = 0.005`），
工具车屏幕框 `[377,445,623,624]` 右缘与车床 `[621,305,1169,568]` 左缘相接。
允许在 ±15% 内微调距离，要求：**车床占画幅宽 30%–40%、工具车 ≥ 14%、两件全在画幅内**。
⚠️ 此预设下 `hRatio ≈ 0.68` 属于正常（工具车更近相机），**不要为了压这个数去改工具车尺度**。

### ③ `layout()`：判据重述 + 新增 HUD/小地图避让
**(a) W8 重述为四条**（`checks` 里逐条列出，阈值写清楚）：

| id | 类型 | 判据 |
|---|---|---|
| `W8.scale` | **硬** | `toolcart.scale = (1, 1, 1)`（不随车床 ×1.4） |
| `W8.height` | **硬** | `userData.height = 0.92 ± 0.02` |
| `W8.boxLocal` | **硬** | 未旋转包箱 = `1.16 / 1.10 × 0.92 × 0.60 / 0.55`（±0.03） |
| `W8.hRatio` | 软（粗筛） | **`0.38 ≤ hRatio ≤ 0.58`** —— 只防量级错误（若误随车床 ×1.4 会冲到 ≈0.68） |

**(b) 重叠判据把分母写进 `name`，两个都卡紧**（这样以后不用再争分母）：
```js
toolcart: {
  latheCovered:     <交集 ÷ 车床屏幕框>,    //  规范判据：工具车不得压住车床
  overlapWithLathe: <交集 ÷ 工具车屏幕框>,  //  诊断值：工具车被车床"吃掉"多少
  mapHitPct:        <交集 ÷ 工具车屏幕框>,  //  HUD 避让：与右下小地图的重叠占比
  screen, pos, scale, height, boxLocal, hRatio,
}
```
- `W8.cover`：`latheCovered ≤ 0.10`（定稿位实测 **0.005**）
- `W8.sep`：`overlapWithLathe ≤ 0.20`（定稿位实测 **0.036**）

**(c) 新增 `overlays`：从 DOM 实测悬浮层矩形**（**不要写死数字**，版面一改就失效）
```js
overlays: {
  minimap: [1236, 756, 1416, 876],   // document.querySelector('.minimap').getBoundingClientRect()
  hud:     [0, 0, 1440, 56],         // document.querySelector('.hud') 的 rect
}
```
**(d) 新增判据 `W9.map`**：`工具车屏幕框 ∩ overlays.minimap = 0`（`mapHitPct === 0`）。
顺带把车床、砂箱也各查一条（现值都不冲突，只是防回归）：`W9.map.lathe` / `W9.map.sandboxes`。

**(e) `checks` 每条继续带 `threshold / value / ok`，`pass` 仍由 `checks` 汇总**；本轮之后阈值不许再无故变动。
⚠️ 别忘了把 `'W9.'` 加进 `needPrefix` 数组（`V8.checks` 靠它检查"每个前缀都有判据"，漏加会自报缺失）。
