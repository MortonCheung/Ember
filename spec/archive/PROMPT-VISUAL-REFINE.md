## W1 · 地面（三页统一）

**唯一的铁律**：**脏必须有理由、成片、低对比。随机小斑 + 高频噪点一律不许出现。**

### W1-a 三页地面参数（数值即规格）

| 场景 | 尺寸 | 位置 | 基色 | `roughness` | `metalness` | `repeat` |
|---|---|---|---|---|---|---|
| 铸造馆 | `PlaneGeometry(40, 60)` | `(0,0,0)` | `0x23282F` | **0.42** | **0.22** | **(8, 12)** |
| 序厅 | `PlaneGeometry(60, 60)` | `(0,0,0)` | `0x171C23` | **0.40** | **0.24** | **(12, 12)** |

| 层 | 值 |
|---|---|

## W2 · 序厅《炉前》建模细化

**前提：`ENTRANCE-FURNACE-SPEC §2` 的坐标一个都不动**（E1a–E1f / E2b 全保持）。下面的改动**全是"贴皮与构件"，不是"挪东西"**。

### Q2.1 炉膛有纵深（最高性价比）

- 腔体材质：`color 0x1A0E08 → **0x3A2318**`、`roughness 0.85 → 0.9`、`metalness 0.05 → 0`。**几何与 `side: BackSide` 都不动。**
  > 为什么：`0x1A0E08` 线性反照率 ≈0.008，点光在腔壁上**画不出任何渐变**（你上轮 §4.3 证明过同一个物理事实）。抬亮后腔底受光、腔顶背光，透过拱口就能看见一道上下渐变 —— **纵深由此而来**。
- 腔体后壁前 0.10 m（`z = −19.50`）贴 **24 条横向耐火砖缝**：`PlaneGeometry(12, 0.05)`，`y` 从 `1.60` 起每 `0.38` 一条，色 `0x32200F`。
- 腔侧壁 / 腔顶**不加东西**，让光区分。

### Q2.2 炉床 → 熔池（去掉台阶感）

现在两片矩形拼出**一个边界笔直的亮色梯形** = 台阶。改成"**一片径向渐变椭圆池 + 一圈池沿**"：

| 件 | 几何 | 位置 | 颜色 |
|---|---|---|---|
| 液面 | `CircleGeometry(5.6, 32)`，`scale(1,1,0.90)`，`rotateX(-π/2)` | `(0, 1.35, −17.1)` | 顶点色径向：`0 → 0xFFE7C0`、`0.55 → 0xE8663C`、`1.0 → 0x8E3418`。`MeshBasicMaterial({ vertexColors: true, side: DoubleSide })` |
| 池沿 | 4 段 `Box`（宽 0.60 / 高 0.35）围一圈 | `y 1.35…1.70` | `0x2A1A12`，Standard |

⚠️ **E5① 必须保住**：探针 5 点距池心 ≤ 3.1 m（= 半径的 0.55 倍）。
→ **硬约束：`r/5.6 ≤ 0.60` 范围内顶点色不得低于 `0xFFC98A` 的亮度**（渐变在 `r ≤ 3.4 m` 内保持"平顶"，之后才衰减）。违背 → `E5①` 从 207 掉破 200 → **判失败**。

### Q2.3 飘火 → 圆点火星（现在是大黄方块）

`furnace` 机位距墙 `14.24 m`、画幅高 `14.58 m`，`size 0.14` 在屏上约 **8.6 px 的方块**。规格 §2.8 那句"此尺度下方形即读作火星"是**按 default 机位（34 m）算的**，furnace 机位不成立。

→ `PointsMaterial` 换成 **`ShaderMaterial` + `gl_PointCoord` 圆形软遮罩**（**零贴图增量**，`§8.5` 维持）：

```glsl
// fragment
float r = length(gl_PointCoord - 0.5) * 2.0;
if (r > 1.0) discard;
float soft = smoothstep(1.0, 0.15, r);
float core = smoothstep(0.55, 0.0, r);
gl_FragColor = vec4(uColor * (0.65 + 0.75 * core), soft * uOpacity * vFade);
```

| 参数 | 新值 |
|---|---|
| `EMBER_N` | 180 → **140** |
| 逐粒子尺寸 | **0.06…0.13**（`rnd(i+7000)`），不再统一 0.14 |
| 出生盒 x | **±5.6**（= 炉口净宽半值，让飘火**从炉口出来**，不再浮在实心墙上） |
| 出生盒 y | `1.2…8.0`（原到 10，会飘到拱顶以上） |
| 出生盒 z | `−13.8…+2.0` |

逐粒子运动公式**不变**，只换渲染方式与出生盒。

### Q3.5 浇注动画（五段，总 3400 ms）

**现在按下「开始浇注」什么也没发生** —— 只有砂箱抬起来开箱。**一个叫"亲手浇铸"的互动，没有浇注动作。**

在**同一条 `update(t)` 时间线**上补四段（帧差 50 ms 上限与 `E10` 纪律**保持**）：

| 段 | 时间 | 内容 |
|---|---|---|
| **A 就位** | `0–700` | 浇包从休息位移到**目标箱正上方**（箱心 + 0.85 m 高 2.55 m）；`easeInOutCubic`；路径带 **0.45 m 抬升弧**（中途 y 最高 3.30）；熔面轻微晃动 `±3°` |
| **B 倾包** | `700–1250` | 倾角 0 → **52°**；**铁水流出现**：`CylinderGeometry(0.045, 0.07, 1, 10)` 单位高沿 y 缩放，顶接浇嘴、底落**浇口盆**；截面半径 0.04 → 0.075 |
| **C 充型** | `1250–2200` | 流稳定；**落点火花**（复用现有 110 粒子管线，改在落点生成）；目标箱 `instanceColor` 叠暖色 `(1.25, 1.05, 0.80)`；箱体轻微震动 `±0.008 m @ 12 Hz` |
| **D 收流离开** | `2200–2700` | 倾角回 0；流变细到 0.02 后消失；火花衰减；浇包升至 `y 3.30` 并水平退回休息位 |
| **E 开箱** | `2700–3400` | **复用现有开箱**：上箱抬升 `1.15 m` + 型砂粒子 + 铸件出现；**铸件同时开始冷却**（Q3.6） |

- 全部动作走**同一条 `update()`**，仍由 `cast.js` 步骤机驱动；`goStep(3)`（"铁水充型中"）覆盖 A–D 段，**沿用现有 `onDone` 链路**在 E 段末触发 `goStep(4)`。
- `finishOpen()`（「跳过」）→ `progress = TOTAL`，**一次落到 E 段末尾**。
- `reduced-motion` → 跳过 A–D，直接 E 段静态落位。
- `resetBoxes()` → 浇包回休息位、倾角归零、流与火花隐藏、铸件隐藏。
- ⚠️ 铁水流的高度**用 `mesh.scale.y` 缩放，不许重建几何**。
- ⚠️ **不许 `Math.random()`**（火花沿用 sin 哈希）。
