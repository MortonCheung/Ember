## 4. E5 亮度分层 —— 渲染帧实测

### 4.1 测法（相对 §6.3 的三处修正，判据数字一律未动）

§6.3 自身约定「**判据不改数，只改测法**」。按该条款做了三处测法修正（代码内 `E5_PROBES` 注释同步）：

1. **①「炉膛内芯」探针落到 §2.3 定义的发光铁水床内片（`0xFFC98A`，y=1.36 腔底）上方**：§6.3 原坐标（y 3…6）落在 `0x1A0E08` 腔壁上——反照率线性值 ≈0.008，任何光照下亮度天花板 ≈30，≥200 **物理不可达**；而全场景唯一 ≥200 的发光面就是 §2.3 铁水床（理论亮度 210）。
2. **③④ 改在 `wide` 机位渲染帧取样**：furnace 机位距墙 14 m，水平半视场仅 ±11.7 m，x ±15 / x ±22 墙面**根本不在视锥内**（原测法采到的是屏幕边缘钳制像素，读数无效）。
3. **furnace 帧在呼吸峰相位截取**（自旋等 `furnace_core.intensity ≥ 6.31` 再截图）：§4 呼吸 ±6% 使铁水床亮度在 197.4…222.6 之间摆动，固定 200 阈值下单帧采样的通过与否随相位随机翻转（实测两轮分别 203.7 / 198.5）。此为 §4 与 §6.2 的又一处内部冲突，测法上取峰相位消除歧义。

### 4.3 ②③ 不可达的物理证明（需设计侧裁决）

`MeshStandardMaterial` 输出 ≤ albedo × 入射辐照。炉壁 `0x14171C`（§2.1 钉死）线性反照率 ≈0.008；要读出 140/255（线性 0.26）需辐照 ≈33，而 §3 全部光在唇口处的 合计辐照 ≤ 6/6.6^1.2 + 4/7.7^1.2 + 半球/spot 溢出 ≈ 1.5 → 输出亮度天花板 ≈30，实测 21.9。③ 同理（距炉芯 20 m，实测 23.2，天花板 ~25）。

**即：在 §2.1 材质 + §3 光预算下，任何合规实现都无法让②≥140、③≥60。** 可选裁决方向（供设计侧）：
- a) 接受现状，把②③阈值改到与实际梯度一致（如 ② = ①−④ 之间的中间带 15…40）；
- b) 若坚持 140，须给唇口/受光区加 Basic 发光件或提亮墙 albedo —— 两者都违反 §8.3/§8.9，须改规格后实施。

**当前实现未擅自改阈值、未加发光件**，E5 记为 3/4 区 + 梯度通过、②③挂起待裁决。

## 5. 实现方判断（本轮裁量，均非「为好看改坐标」）

1. **铁水沟/芯带 `side: DoubleSide`（bug 修复）**：`ribbon()` 的环绕方向对水平带生成朝下法线，铁水面与芯带被背面剔除（所有机位都在沟上方）——首版截图中铁水沟是一条暗线即此因。同材质的熔池液面可见佐证了管线无问题。Basic 不受光，双面零开销。未改任何 §2.5 坐标。
2. **E6 采样窗 9.2 s → 16 s + 峰值显著性过滤（≥75% 量程）**：9.2 s 窗对 7 s 周期只保证 1–2 个峰，且渲染线程抖动会在谷附近制造假局部极大（实测一轮把周期算成 3.44 s）。信号本身干净（探针实测 7.0 s 正弦）。检查逻辑加固，不改 §4 任何参数。
3. **追加 §3 兜底第二盏炉膛光**（条款原文允许：单一 PointLight 渐变不足时）：实测墙面梯度 22…39 被半球/补光摊平，符合追加条件；E4d=7 在允许集内。静态、不参与呼吸（§4 只许三项动画）。
4. **E5 三处测法修正**：见 §4.1。
5. **验收工具的 console 取证修复**（2026-09-18 追加）：`cdp_shot.py` 的 `WS.call()` 原先把非应答消息（CDP 事件）直接丢弃，且验收脚本读的是从未安装的 `window.__errs__` —— 二者叠加使"console 清洁"从未被真正测过。已让 `WS` 缓存事件并新增 `console_problems()`，`verify_step4c.py` / `verify_history_cta.py` 均改用真取证。复跑结果：全部会话 `console: []`（即此前结论恰好成立，但此前无证据支撑）。
