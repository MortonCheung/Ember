## 0. 怎么开始

```bash
cd source/app
npx vite --host 127.0.0.1        # → http://127.0.0.1:5173/#/journey
```

调试导演台（强烈建议开，走查时改用得着）：

```
http://127.0.0.1:5173/?debug=1#/journey
```

| 命令（浏览器控制台） | 用途 |
|---|---|
| `__liaoji.listShots()` | 全片 48 个镜头表（id / 章节 / 区间 / 权重 / 是否硬切 / 可否互动） |
| `__liaoji.setShot('FS_05_LAND', 1)` | 直接跳到某个镜头的某个时刻 —— 想反复看同一镜就用它 |
| `__liaoji.showPaths()` | 一次画出全片相机 Position（青）/ Target（橙）双路径 |
| `__liaoji.shotContinuity()` | 非硬切镜头的首尾衔接体检 |
| `__liaoji.worldState()` | 门 / 列车 / 炉温 / 卡车 / 电铲等关键状态读数 |
| `__liaoji.pickCenter(0,0)` | 拾取画面中央物体（定位「这挡住画面的是什么」） |

**自动验收**（已全绿，只证明「没坏」，不能替代人眼）：

```bash
python3 tools/verify_journey.py http://127.0.0.1:5173          # 27 项
python3 tools/walkthrough_cinematic.py http://127.0.0.1:5173   # 25 项（三遍的可复现版）
```

## 1. Pass A —— 纯看，不点任何东西（约 8 分钟）

一次滚到底，中途**不要点 marker、不要点工件**。判据是「像不像一部电影」，不是「有没有 bug」。

- [ ] **开场**：黑场 → 开关咔哒 → 灯亮 → 主轴转 → 钢缆绷紧 → 铁水 → 卡尺 → 车轮 → 标题 → 大门打开。
      像电影开场，而不是网站 Hero。
- [ ] **沈阳**：进门就是纵深，天吊在动、浇包在倾斜、工人各干各的 —— 走的全程世界一直有事发生，不是「走走走→到展品才有动画」。
- [ ] Camera **没有乱转头**（旧版「先走→随便看→猛回头」的毛病已消除）。
- [ ] 墙上的「沈阳 · 机器 / 1950s · 铁西」是**建筑的一部分**，随相机进入和离开画面，不是浮在屏幕上的字。
- [ ] C620-1 **提前十几米就能看见**，路线自然把你带过去，不是突然出现。
- [ ] 走出厂房后**直接进入铁路**（不是 loading 画面），列车在动，字幕「铁矿石 / 运输 / 鞍山」随行进出现。
- [ ] 矿石充满画面 → 下一镜你已经在高炉里了（**身份转换没有任何文字提示**，但你应该自己意识到了）。
- [ ] **鞍山**：上料 → 炉内下降（物料向下、热气向上）→ 冷灰变红熔融 → 出铁冲出炉口。
      你应该清楚感到自己从「参观者」变成了「材料」。
- [ ] 蒙太奇（倾倒 / 火花 / 钢坯 / 轧辊 / 钢板贴脸）**不拖沓**。
- [ ] 钢板变成 1950s 工业卡车 —— 是电影式的 Match Transition，不是制造模拟。
- [ ] 公路段有内容（环境在变：厂房→铁塔→土路→山体），不是空转场。
- [ ] **抚顺**：地平线断开 → 看见矿坑 → 俯冲 → 落到工人脚边。
      低机位让工人显得高大，但**整个矿坑比他更加巨大**（两个尺度同时成立）。
- [ ] 工人双手叉腰、抬头看天；你自然跟着他的视线往上看。
- [ ] **结尾**回到那个年代的人 / 劳动 / 自豪，**没有**跑向未来、没有「因为他们才有今天」式的升华。

## 2. Pass B —— 所有互动都点一遍（约 5 分钟）

- [ ] **C620-1**：靠近时工作灯稍亮、部件轻微错位再合拢（Notice ≈0.7s），随后出现「○ 触碰机器」。
      **不点也能直接滚过去**（不是关卡）。
- [ ] 点进去：相机是**导演好的固定进入镜头**，进去之后才允许少量局部观察（不是自由乱转）。
- [ ] 自动**拆解**成 床身 / 主轴箱 / 刀架·溜板 / 尾座 —— 像工业分解图，**不是爆炸**。
- [ ] 点任一部件 → 出现该部件的一句话说明（不是百科）。
- [ ] 「组装并启动」→ 部件回位 → 工作灯亮 → 主轴转起来。
- [ ] 拖**手轮** → 刀架移动 → 车刀接触 → 切屑飞出（不做复杂材料仿真，够读就行）。
- [ ] 进给到满 → 出现 **C620-1 / 1955 / 沈阳第一机床厂** 的历史信息。
- [ ] 退出后**回到原来的位置**（自动断言要求误差 <0.6m，人眼应感觉「原地返回」）。
- [ ] **工作台**（出口附近，全片唯一的生活化小场景）：点图纸展开、点卡尺抬起；搪瓷杯/暖水瓶不互动。
      整个互动 10~15 秒，不啰嗦。
- [ ] 全程没有任何弹窗、没有劫持滚动、没有第二条页面。

## 3. Pass C —— 反向滚（约 5 分钟）

从结尾一路往**回**滚，重点看这些地方：

- [ ] 动画**不倒放崩坏**（不是「倒带」，而是「同一个进度就是同一帧画面」）。
- [ ] 门、列车、卡车、炉温、钢板位置在你往回滚时**回到它们当时该在的状态**，不是停在最后一次路过的地方。
- [ ] 反向进入 Explore 再退出，仍然原地返回。
- [ ] 快速来回拖动滚动条，画面不闪、不抖、不跳。
- [ ] （可选）缩到 390px 宽：能跑、布局不炸。正式电影构图以 1440×900 / 1280×720 为准。
