## 2. 这个作品的立意（很重要，别做成普通官网）

**「炉火不灭」**

一句话：**把一座已被封存的车间，重启为一台可以对谈的机器。**

中国工业博物馆的铸造馆，是原沈阳铸造厂的翻砂车间原址。里面那台十吨冲天炉，1957 年投用、2007 年熄火，熔化过近百万吨铁水，生产铸件 60 余万吨，现在是全国重点文物保护单位里一个静止的"工业琥珀"。

我们做的事：**让它重新点火，但点火的人是观众。**

所以这不是一个"信息展示网站"，是一个**参与式叙事**。四层体验递进：

| 层 | 名称 | 用户做什么 |
|---|---|---|
| 01 | 看见 · 云端铁西 | 认识铁西"东方鲁尔"的分量 |
| 02 | 看懂 · 铁流凝变 | 理解这些机器为什么重要 |
| 03 | 参与 · 车间劳作 | **亲手浇铸、亲手车削**（创意峰值） |
| 04 | 带走 · 炉火不灭 | 生成专属数字工牌 |

**第 03 层是整个作品的灵魂。** 不是"点开看视频"，而是"你操作参数 → 铸件质量因此改变 → 你被评分"。

### 9.3 ⚠️ 关于 shell 的坑（仅影响 AI 代理，不影响你自己的终端）

**先说结论：你在自己的 cmd / PowerShell 7 里敲命令，一切正常，随便用管道。**
这一节只对"AI 代理替我执行命令"的场景有效。

**原因**：WorkBuddy 内置了一个**精简过的 PortableGit** 作为 AI 的命令执行环境，位置在
`C:\Users\savetime\.workbuddy\binaries\PortableGit\versions\1.2.0\bin\`，
里面**只有一个文件：`bash.exe`**。正常 Git for Windows 该目录下有 150 多个 GNU 命令，
这个版本把 `tail`、`ls`、`dirname`、`sed`、`awk` 全部剥掉了。

后果：**AI 执行的带管道命令会假报失败**。例如：

```bash
npm install 2>&1 | tail -20     # ❌ AI 执行时显示 failed，但其实 npm 已经装完了
```

失败的是 `tail`（不存在），不是 `npm`。管道右侧一崩，整个命令退出码就是非 0。

**如果你在让 AI 帮你执行命令**，请这样规避：
1. 告诉它**不要用管道 `|`**，直接跑命令看原始输出
2. 需要列目录 / 操作文件 → 让它走 PowerShell，不要走 bash
3. 判断是否成功 → **看命令自己的输出**（如 npm 打印 `added N packages`），别只看退出码

**如果你自己敲**：无需任何规避，正常用。

### 9.4 无头截图（需要时）

环境里有 Edge（`C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`）。
注意：Edge 的 `--headless --screenshot=xxx.png` 参数**在本机静默失败**（返回码 0 但不产文件），必须走 CDP（Chrome DevTools Protocol）。
