## 3. 偏离与裁定留痕（**实现方判断**）

1. **协作分封顶口径**：`TURN-SPEC §4.2` 把 `min(40,…)` 写在两项之和外，但 `§8 U3` 算例与
   `PROMPT-TURN` 算例两处独立给出 ①20/②100/③100/④20，按「逐维各封顶一次」才能复现
   （`fDev×20` 与 `nDev×20` 各 `min(40,…)` 后相加）。**取逐维封顶**，与两处算例一致。
2. **U3④ 入榜=false**：规格 `§8 U3④` 写「是（强制结算）」，但 `§3.2/§3.7/§6` 硬门槛
   「质量分 ≥60 且 t ≥10 s」、`§6` 规定低于门槛不写 `im.turn.best`。36 < 60 →
   **实现为不入榜**（rank=null、末位、标「未入榜」）。断言已固化该裁定（`turning.js` selfTest）。
3. **榜单本局恒占一行**：未达门槛若整行移除，版式从 3 行塌成 2 行。实现为**本局恒占一行**
   （未入榜排末位、rank 显示「—」、加「未入榜」标签），初始态同理居中占位。
4. **U9b console 3 条说明**（`--disable-webgl2` 强制 WebGL1 实例）：① `THREE.WebGLRenderer:
   A WebGL context could not be created` —— 是 `--disable-webgl2` 开关使 webgl2 首选上下文
   创建失败的**预期报错**，随后回退 WebGL1 成功（页面 wired=true、正常渲染与结算）；
   ② WebGL1 deprecation 通告（three.js r153+ 固有）；③ PMREM 环境贴图在 WebGL1 下被
   重采样提示。三条均为测试环境产物，非页面缺陷；正常 WebGL2 环境五页 console 为 0。

## 5. 修订记录

### R1 · 2026-09-21 晚（用户验收反馈，三项全改）

用户反馈：① 删左下角两个角色标签；② 动画粗糙、看不出在做什么；③ 车床上方有悬空物体。

**诊断（CDP 世界盒实测，非目测）**：②③ 同根 ——
- **`turn_tool_shank` 世界盒 y ≈ 5.89–5.99**（工件主轴 y=2.97、车床顶 3.99）：
  `shank` 是 `tool` 组子对象，父子**各加了一次** `(xt, SPINDLE_Y, …)` 偏移 → 刀杆悬空，
  **切点上没有刀**（= 悬空物体 = 看不出在切削的主因）。
- **相机被外推**：viewport.js 挂载时 `minDistance=6` 的 `controls.update()` 把 2.05 的设计机位
  沿视线推到 **6.03**，turn.js 事后下调 minDistance 但相机不回位 → 全场景小一半，
  六级台阶每级仅 2–3 px，读作「锥形棒」。

**修复与增强**（全部零贴图、零随机，动画仍固定 3600 ms、poseAt 仍为纯函数）：
1. `shank.position` 只补径向 z（父组承担轴向/高度）—— 悬空物体消失，切点有刀；
2. 相机：下调 minDistance 后**显式放回设计位**，并按实测重调为
   `pos [0.55, 4.00, 2.10] / target [0.05, 2.96, 0]`（对准切削区中点，距 2.40）；
3. 工件加**顶点色**：毛坯暗 `#59616B` → 已加工亮钢 `#C7D0DA` 随刀架渐变
   （「切削前沿」跟着刀尖走）+ 纵向条纹（col 1–2，随主轴转 → 转速可读）；
4. 切屑重调：150 粒、从切削点前上方抛出成弧、尺寸 0.007–0.015；
5. 新增**切削点热斑**（4 粒加色混合 Points，B 段显示，确定性闪烁）。
6. 角色药丸整组删除（DOM + CSS + 响应式引用），`TURN-SPEC §2` 加 ⛔ 裁定注。

**回归**：`verify_turn.py` 重跑 **30/30 PASS**；性能 calls 9 / tri 3,914 / tex 2 全部达标。
（U7.replayPlayback 首跑超时是测试时序：回放每帧限推 50 ms × SwiftShader 低 rAF ⇒
放完 4.6 s 录像需 >5.5 s —— 验收脚本改为轮询至上限 15 s，功能本身无回归。）

### R2 · 2026-09-22（用户验收反馈：建模三项）

用户反馈：① 一端圆锥插入铁块、另一端大量异常尖刺；② 铁块透视观感不对；③ 整体细化建模。

**诊断（世界盒 + 投影 + 逐行半径扫描，非目测）——①② 同根**：
剔除框（质心法）把两个**跨边界零件拦腰斩断**：
- **自带卡盘**（cyl r0.16 @ x −0.53…−0.33）：侧壁三角形质心 T1=−0.463 / T2=−0.397，
  原框 x0=−0.40 只斩掉 T2 ⇒ 交替删除成「鳍刺」，散在铁块左端周围（用户看到的
  「椭圆环」即鳍片弧）；
- **尾座顶尖**（锥 x 0.16…0.22）：原框 x1=0.19 斩掉左半 ⇒ 半截锯齿锥悬在铁块右端面外
  （=「尖刺」；完整的锥本该整个藏进毛坯 r0.085 内）；
- **竖向细线**：肩面带 1.5 mm 小条带在两侧行**等径**时贴在圆柱面上，法线却是轴向的
  （⊥ 邻面）⇒ 受光成一圈圈亮/暗竖线，整根毛坯被读成「锥度 / 透视不对」。

**修复**（`lathe.js` 源文件未动，全部在实例几何上）：
1. 剔除框改 `x0 −0.40→−0.37 / x1 0.19→0.23`（逐三角验算：卡盘 T1/T2 完整保留——
   本就藏在本页自建卡盘 r0.17 内；卡盘爪面质心 ±0.35/−0.30 照常剔；主轴箱右面
   −0.53 保留不开洞；顶尖整体剔；套筒侧壁 0.34/0.48 保留）；
2. 毛坯余料 `TAIL_X 0.34→0.37`：端面顶住套筒左端（世界 1.11 > 1.05），兼盖被剔的
   套筒左端盖 ⇒ 「卡盘—工件—顶尖/套筒—尾座」传力链视觉闭合；
3. 肩面法线随几何状态切换：等径 ⇒ 径向（贴面），不等径（真实台阶）⇒ 轴向；
4. 工件材质 `DoubleSide`（环绕时内壁照常着色，杜绝「敞口管」观感）。

**细化**（并入既有材质 ⇒ 零新增 draw call）：
- 卡盘端面：止口环（r0.125）+ 3 组内六角压紧螺钉（六棱，随主轴旋转 ⇒ 转速可读）；
- 方刀台：2 个扳手方头；刀尖：硬质合金刀片。

**回归**：`verify_turn.py` **30/30 PASS**；性能 calls 9 / tri **4,138** / tex 2 全达标
（+224 tri 来自细节件）；车床源文件未动，其余四页门禁照常全过。
