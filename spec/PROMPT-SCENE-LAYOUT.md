## 3. 做什么（五组，硬指标如下；详细坐标表见 SPEC §2–§5、§9）

**① 冲天炉放大 ×1.35（整组等比，基点 y=0）**
- `group.scale.setScalar(1.35)` → 炉身 12m→**16.2m**、底半径 2.4→3.24、炉口环 y 16.01–16.39；屏幕框应变到 **[514,154,886,665]**（372×511）。
- 连带：① 炉火两盏 → `(−6±2.03, 15.12, −8)`，强度 2.4→**3.0**，distance 30→**40**；补光 → `(−6, 5.4, 0.1)`，强度 0.9→**1.2**，distance 22→**30**（灯是绝对坐标，不随 group 缩放，必须手动改）。② 加料平台下加 2 根落地支撑柱（局部 `Box(0.42,8.28,0.42)@(4.6,4.14,±1.3)`）。③ 爬梯局部 z `−2.42→−1.55`、档距 `0.55→0.28`（15→30 档）、平台后缘护栏留 0.9m 梯口。

**② 车床按真实尺寸重建 + 换机位**
- 真实基准：**2410 × 1000 × 1250 mm**。目标：**长 2.53 × 宽 1.02 × 高 1.33 m**。
- ⚠️ **不要用等比缩放**：原模型比例本身就错（床身 0.6 高、主轴箱 1.1 高 → 剪影接近正方形，这就是它"像大方箱"的根因）。按 SPEC §3.2 的 28 行逐件表**重建坐标**，竖向层次固定为：床腿 0–0.42 / 托盘 0.42–0.48 / 床身 0.48–0.80 / 导轨 0.80–0.85 / **主轴中心线 y=0.99（中心高 0.19）** / 主轴箱 0.80–1.14 / 皮带罩 1.14–1.27 / 挂轮罩 1.27–1.33。
- 语义纠正：卡盘在主轴箱**右端面**（正对床身），卡盘→工件→尾座顶尖**由左至右贯通共轴**（y=0.99，四件误差<0.01）。原模型把卡盘放在箱体左侧、工件埋进箱体里，是错的。
- 新机位 `group.position.set(15, 0, -6)`（原 −14,−25）→ 屏幕框应 ≈ **[1184,642,1308,720]**。
- 结构约定不得改：`group.name='lathe_c620'`、三个 mesh 名 `lathe_body/lathe_steel/lathe_plate`（剪影钩子按名字找）、合并方式仍是 2+1 个 mesh（3 draw call）。

**③ 砂箱阵列落位**
- 整组平移 **(−2, 0, −2)**（即 `CENTER (8.5,3) → (6.5,1)`；**或**在 `workshop.js` 里给 group 设 position，二选一，别做两次）。
- 结果应为：世界 x 3.2–9.8、z −3.3–5.3；屏幕框 **[695,620,1040,817]**（下方留 83px，不再被裁）。
- `environment.js` 作业区警示线四段同步平移为：`(2.2,−4.3)-(10.8,−4.3)`、`(2.2,6.3)-(10.8,6.3)`、`(2.2,−4.3)-(2.2,6.3)`、`(10.8,−4.3)-(10.8,6.3)`。
- 地面导向线 x `±8.8 → ±11.5`（理由：11.5 在立柱内缘 12.3 以内 0.8m，改读作"天吊运行区边界线"；且与砂箱作业区、冲天炉炉体都不再交叠）。**不得取 ±12.8–13.7（穿柱）、不得取 ≥±14（贴墙）。** 冲天炉炉前两条线保持不变。

**④ 悬空构件七项（逐项，判据见 SPEC §5）**
1. 吊灯吊杆：杆长 `2.2→11.5`、中心 `y18.4→22.91`（**杆顶 28.66 = 屋架下弦梁底面**，正好抵住）；灯位 z `±18/0 → ±17.33/0`（对齐 7 道横梁）。
2. 加料平台：见 ①。
3. 出铁流槽末端（×1.35 后悬在离地 1.10m）：**新增 `props/ladle.js` 铁水包**，世界位置 **(−6, 0, 0.35)**，`CylinderGeometry(0.80,0.65,1.10,28)` 坐地 + 口沿环 `Torus(0.80,0.05,10,36)@y1.10` + 吊耳；口沿 y=1.10 与流槽末端齐平、z 偏差 <0.2。**不随炉体缩放**（独立 props，挂 workshop）。另加倾动装置 / 吊耳 / 坐圈 / 铁水液面 4 处细节，见 ⑤ 与 SPEC §9.4 D。
4. 炉后爬梯：见 ①。
5. 后墙横管 3 根：`z −29.4 → −29.72`（贴墙）；管长 `W−3 → W−0.6`（端头顶到两侧墙内表面）。
6. 左墙立管：`x −19.4 → −19.72`（贴墙）；高度 `6 → 28.5`（升到屋架）；底部加法兰 `Box(0.34,0.06,0.34)@y0.03`。
7. 天吊端梁下方加轨道梁：`Box(1.6, 1.1, 52) @ (±19.0, 23.05, 0)`，梁顶 23.6 正好接住端梁底。

**⑤ 提高建模精细度（用户追加要求）**
- 现状：全场景只有 **3878 三角面 / 32 draw call**，预算是 **300k / 120** —— 几何只用了 **1.3%**，基本是"预算空着没用"。近观机位下最露怯的三处：**炉身 20 段圆柱**的棱角肉眼可数、**屋架根本不是桁架**（只有 7 道横梁 + 6 根竖直杆，没有上下弦与斜腹杆——注释写"斜拉杆"但代码没旋转）、**吊灯是不透光黑盒**（靠点光假装在发光）。
- **两件事**：① **圆弧件段数上调**（直径 ≥0.5m 的件 36–48 段、0.1–0.5m 的件 20–28 段、细杆 ≥10 段），逐件参数见 SPEC §9.3；② **每件补 3–6 处"表意细节"**（风口环、加强箍、箱耳吊轴、天吊端梁车轮与卷筒、立柱柱脚、窗框竖梃、管道法兰/弯头/吊架……），完整清单见 SPEC §9.4 的 A–G 组。
- **硬约束（不要越界）**：**只加几何、不加新贴图**；细节几何一律 **`mergeGeometries` 并进该 props 已有的 mesh**（冲天炉风口环并进 `cupola_tap`、砂箱细节并进 `lower`/`upper` 的几何……），**不得为细节新开 mesh**；因此 draw call 只需 **+2**（来自新构件铁水包），三角面控制在 **≤60k**。
- **优先级**（时间紧就做到 D）：A 冲天炉 → B 车床 → C 砂箱 → D 铁水包 → F 屋架/立柱 → E 天吊 → G 环境。
- ⚠️ **先按 §3 重建车床，再按 §9.3 改段数**——顺序反了会改到旧模型的参数。§9.6 还列了 5 处"别做重"的交叉点（爬梯档距、轨道梁与车轮、吊杆落点、管道贴墙、车床逐件表），动手前先看一遍。
