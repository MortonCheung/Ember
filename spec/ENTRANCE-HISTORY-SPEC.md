## 1. 序厅 `#/entrance`

### 1.1 定位

观众从首页进入虚拟展厅的**第二站**。真实的序厅陈列博物馆的叙事前提：一座城市为什么会有这些机器。
三维里**只做一件事**：让《铁流凝变》迎面而来。

### 1.2 场景内容（极简，这是刻意的）

| 构件 | 规格 | 说明 |
|---|---|---|
| 《铁流凝变》雕塑 | 见 §1.3 | 唯一主角 |
| 地面 | 一块 `PlaneGeometry`，深色，`roughness .9`，`metalness 0` | 不做油渍贴图（序厅是展厅地面，不是车间） |
| 后墙 | 一面 `PlaneGeometry`（暗） | 给雕塑一个背衬，避免"悬在虚空" |
| 侧墙 | **不做** | 相机活动范围已限制，观众看不到侧墙背面 |
| 灯具模型 | **不做** | 只用光源，不做可见灯具 |
| 顶棚 | **不做** | 相机俯角受限，看不到 |

> **口径**：序厅是"留白"，不是"没做完"。所有非主角构件一律不为它单独建模。
> 观众在这一页只该记住一件东西：那道凝固的钢水。

### 1.3 《铁流凝变》雕塑规格

**史实锚点（不得改）**：长 **22 m**、高 **11.5 m**，凝固新中国第一炉钢水倾泻的瞬间。

| 项 | 值 |
|---|---|
| 包箱（世界） | **x 跨度 22 ± 0.5 m × y 跨度 11.5 ± 0.5 m** |
| 落位 | 世界原点居中；**底面贴 y = 0**（不得悬空） |
| 比例 | **1:1**，`scale` 必须为 `(1,1,1)` |
| 材质 | 青铜 `#6B5B4A`，`metalness .8` / `roughness .35`（`envMapIntensity 0.25`，与全站一致） |
| 网格数 | **必须 merge 成 1 个 mesh** → draw call **+1**，不得拆成十几个 |

**形态（读作"倾泻的瞬间"，不是"一面墙"）**：主体是一道**从左上向右下倾泻的流束**，
横向跨度吃掉 22 m、竖向落差吃掉 11.5 m。必须有这 5 个可辨认特征：

| # | 特征 | 做法（推荐） |
|---|---|---|
| 1 | **主束沿样条走** | 用 `CatmullRomCurve3` 定一条从左上到右下的曲线，沿线取 **12 个截面**（不是直筒） |
| 2 | **半径由窄变宽** | 12 段 `CylinderGeometry(RADIAL, RADIAL, L, 8)`，半径顶部 **0.35 → 中部 0.9 → 底部 2.6** |
| 3 | **截面是扁的** | 每段 `scale.z = 0.55` —— 读作"流淌的带"，不是"柱子" |
| 4 | **落点铺展** | 底部 3 个压扁的 `ConeGeometry`（r 3.2 / 2.4 / 1.6，h 0.7）向两侧摊开，带"卷边"感 |
| 5 | **飞溅碎片** | 4 个小块（0.4–0.9 m）散在落点周围 3–6 m 处，制造"瞬间冻结"的动势 |

- `RADIAL` 段数取 **8**，不下 6（低于 6 会读出多面体）。**总面数目标 ≤ 200**。
- 允许用 `ExtrudeGeometry` 沿同一条样条拉伸扁平截面作为**替代实现**，只要 5 个特征齐备。
- **不做表面流线纹理**（不用贴图，贴图 0 增量）。纵向高光由几何起伏 + 顶光自然产生；
  若剪影达标但正面读不出"流"，可在主束上沿流向并 **8–12 条细长凸棱**（并入同一 mesh）。

> ❌ **不要做成"贴墙的浮雕长卷"**：那样观众看不到体量，首页飞越第二章的"迎面而来"也不成立。
> 22 m 是**横向跨度**，不是"一堵墙的宽度"。

### 1.4 光照

| 灯 | 规格 | 作用 |
|---|---|---|
| 环境 | `HemisphereLight` 0.35 / 0.15 | 极暗底，别让雕塑"发灰" |
| **顶部单向聚光** | `SpotLight`，强度 **3.2**，`distance 46`，`decay 1.4`，`angle 0.32`，`penumbra 0.6`，目标对准雕塑中心 | **唯一主角光**：强化"凝固瞬间"的戏剧性 |
| 补光 | `DirectionalLight` 0.25，从右前下方 | 只用于让暗部不糊成一片 |

- **`scene.environment` 沿用全站做法**（`PMREMGenerator` + `RoomEnvironment` + 逐材质 `envMapIntensity 0.25`）。
  ⚠️ `Scene.environmentIntensity` 是 three **r163+** 才有的 API，本项目锁 `^0.160`，**不要写它**。
- 暖色（铁水橙系）在本页**只由聚光产生**，不要给雕塑上橙色材质——它是**凝固的**钢水，青铜底色。

### 1.5 机位与控制

| 预设 | `pos` | `target` | 半径 | 用途 |
|---|---|---|---|---|
| `default` | `[0, 2.2, 16]` | `[0, 5.2, 0]` | **16.28** | 站在序厅入口，正对雕塑 |
| `sculpture` | `[6.4, 3.4, 7.2]` | `[0, 4.6, 0]` | **9.71** | 近观，读流线细节 |

## 2. 通史馆 `#/history`

### 2.1 定位

**不是三维馆，是 2D 长卷。** 它补的是四层体验里唯一没有载体的第 02 层「看懂 · 铁流凝变」：
让观众在进入车间之前，先知道这座城市是怎么变成"东方鲁尔"的。

**为什么不做三维**：史实是**文本与年份**，三维化只会把它变成一堆空展板；
而立项成本是真三维馆的一半以上。2D 长卷是这一层的最优解 —— 便宜、可读、零性能风险。

这是两轮裁定的结果，两轮都记在这里，防止实现方按旧口径做。

---

#### 第一轮（已作废）：曾短暂删除

用户先裁定删掉原来的 `今天，由你点火 →`，两条理由当时成立：

1. **入口重复到第三次。** 铸造馆 `#/hall` 的信息卡 CTA 是**三个热点共用一枚按钮**（`hall.js` 的 `exhibit-card__cta`），其中「十吨冲天炉」「成型砂箱」两个热点都指向 `#/cast`。通史馆再来一枚去 `#/cast` 的，是同一目的地的第三个入口。
2. **文案承诺的动作与落点对不上。** 「今天，由你点火」说的是**点火**，而 `#/cast` 做的是**浇注参数**互动（铁水温度 / 浇注速度 / 砂型湿度 → 评分），全程并没有"点火"这个动作。

> ⛔ **注意：第一轮"删除"的结论已作废**，不要在实现里留"按钮不存在"的判断。

---

#### 第二轮（当前有效）：改为「观看铸造馆 →」，去 `#/hall`

用户改主意：长卷结尾**应该有出口**，但要去**对的地方**、说**对的话**。

- **改文案**：`今天，由你点火 →` → **`观看铸造馆 →`**。
  「点火」与浇注参数互动不搭的问题在**换词**里解决：长卷末尾要的是"去看看那座再也不会点火的冲天炉"，不是一个替观众动手的承诺。
- **改落点**：`#/cast` → **`#/hall`**。
  第 02 层「看懂」的下一站是**去看铸造馆本体**（第 03 层参与式互动的入口在铸造馆里，由铸造馆的三枚热点负责），而不是绕过铸造馆直接跳进浇铸页。
  这样入口不再重复：浇铸页的两个入口仍然只在铸造馆；通史馆给的是**空间导航**（去下一站），不是**抢铸造馆的活**。

> **用词订正：是「铸造馆」，不是「铸造厂」。** 两个词在本项目里指的不是同一件事：
> - **铸造厂** = 历史上的**原沈阳铸造厂**（翻砂车间）——长卷第 3 节点正文里用的就是它：「服务于原沈阳铸造厂的翻砂车间」；
> - **铸造馆** = **观众今天走进的这座场馆**，也是全站导航药丸的名字（序厅 / 通史馆 / 铸造馆 / 机床馆 / 汽车馆）。
>
> 按钮的落点是 `#/hall`，即**场馆**，所以必须写「馆」。用「厂」会把一个空间导航写成对历史实体的回访，且与导航药丸的命名打架。
> 另外去掉原拟文案里的语气词「吧」——主按钮要与同一页 HUD 的「进入铸造馆」保持同一种语气，不做口语化收尾。

**实现改动**（`demo/src/js/pages/history.js`）：

| 位置 | 动作 |
|---|---|
| `NODES` 最后一节点的 `finale: true` | **保留**（第一轮曾计划删除，现恢复） |
| 模板里末节点的按钮 | `<button class="btn btn--primary timeline__cta" type="button" data-go="hall">观看铸造馆 →</button>` |
| 按钮 `copy` | `今天，由你点火 →` → **`观看铸造馆 →`** |
| 按钮 `data-go` | `cast` → **`hall`** |
| 页面级 `page.addEventListener('click', onClick)` 与 `[data-go]` 委托 | **保留**，无需新增分支 —— 既有委托已能路由 `#/hall`（HUD 的 `进入铸造馆` 本来就走它） |
| `.timeline__cta` CSS | **保留**（`layout.css` 已有，不动样式） |

**不改**：第 8 节点本身的年份 / 标题 / 正文（`今天` / `由你点火` / `铸造馆里的冲天炉不会再点火了。但你可以。`）、`长卷续接提示`、HUD 右上角 `进入铸造馆`、五枚药丸、其余 7 个节点。

> **两个出口的分工**（别把它们看成重复）：
> HUD 右上角「进入铸造馆」是**常驻导航**；长卷结尾这枚是**读完之后给出的下一步**。
> 两者都去 `#/hall`，但一个是随时可用、一个是叙事终点 —— 这正是长卷该有的收尾。

> **设计稿同步**：画布 S08 的结尾主按钮已改。旧节点 `7:92`（含子 `7:93`）已删除，新节点 `11:1`（含子 `11:2`）已插入到 `7:68 长卷内容`，文案 `观看铸造馆 →`；`7:91 长卷续接提示` 上移让位。`design/S08-通史馆长卷.png` 已按新版重新导出（1440×900）。
