## 一、为什么归档，而不是删

这个项目已经踩过一次坑：**过期的提示词比没有提示词更危险**。

`spec/PROMPT-ENTRANCE-HISTORY.md` 是 Step 4 的历史交接件，它 §① 写的序厅方向是《铁流凝变》雕塑。
那份方向后来被 Step 4C《炉前》取代，但文件本身还在 `spec/` 里、还叫「交接提示词」——
**任何一次「把 spec 里的提示词发出去」都可能让实现方把序厅做回已作废的方向。**

所以处置原则是：**离开工作目录，但保留可追溯性**。
