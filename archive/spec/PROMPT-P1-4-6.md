## 1. 取证：本批的目标值全部来自**画稿像素实测**

> 红线 2：**代码推出来的目标值 ≠ 画稿口径**。P1-1/P1-2 就是照代码量了头部 56、标记 20×20，
> 结果被画稿翻案成 64、26×26。本批**先量画稿，再定目标值**。

### 1.1 方法：两种，先校验再用

画稿与渲染截图**同为 1440×900**，可以 1:1 对比。脚本落在 `.workbuddy/`：

| 脚本 | 量什么 | 产物 |
|---|---|---|
| `probe_radius_area.py` | 圆角：**角部缺失面积法** | `shots/radius_area.json` |
| `probe_radius_ruler.py` | 圆角：**合成尺**（真实角部 vs 合成 r=2/3/4/6/8…，同倍放大） | `shots/radius_ruler.png` |
| `probe_bands.py` / 内联扫描 | 文字**行带**（同窗口同阈值，两图对扫） | 控制台 |
| `probe_zoom_pairs.py` | 画稿 vs 渲染 **并排放大图** | `shots/scale_compare_zoom.png` |

**面积法**（本批唯一用于出目标值的方法）：
取包围盒左上角 `K×K` 窗（`K = min(w,h)/2`），用亮度把像素折算成覆盖率 `α∈[0,1]`，
缺失面积 `M = Σ(1-α)`；圆角矩形角部缺失面积 `= r²(1-π/4)` ⇒ `r = sqrt(M / 0.21460)`。

**校验（在渲染截图上做，那里 CSS 圆角已知）**：

| 元素 | CSS 已知 | 面积法读数 | 误差 |
|---|---|---|---|
| 主按钮 `.btn`（1440 首页） | `12px` | **11.9** | −0.1 |
| 品牌标记 26×26 | `6px` | **6.0** | ±0.0 |

**±0.1px 的误差 ⇒ 可用于 1px 级的档位判定。** 方法的适用边界（别越界用）：
只对**实心同色块**有效；对渐变填充、描边环、以及角部窗口内有文字/子元素的大面板**不成立**。

**⛔ 两种方法本批试过并弃用（留档，免得下一个人重走）**：

| 弃用方法 | 为什么弃 |
|---|---|
| 「首行内缩量 = r」（A 轮） | 抗锯齿半透明边介于包围盒边与不透明内部之间 ⇒ **不稳定**：同一张画稿的品牌标记读 **3**，面积法+合成尺读 **3.6**；而它在渲染图上读 6.0 对 CSS 6。**改判据 = 掩盖问题**，所以换方法不换结论 |
| 「外轮廓法」（α = 像不像底色） | 在渲染主按钮上读 **15.0** vs CSS 12（**+3.0 误差**），且窗口里相邻元素/光晕会污染包围盒 ⇒ 误差比结论大 |
