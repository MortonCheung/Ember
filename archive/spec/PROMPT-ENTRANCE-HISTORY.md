## 为什么做这两页（不是"顺手加馆"）

场馆导航上的五个药丸是照抄真实馆体结构，**但不等于五个馆都做**。设计侧已裁定：

- **机床馆不做** —— C620-1 车床已经作为展品放在铸造馆里了（还是三个热点药丸之一），单开一馆是同一台机器摆两遍。
- **汽车馆不做** —— `PROJECT-BRIEF.md` §4 的真实素材清单里没有任何汽车内容，做它就得现编史实。
- **成本与评分不匹配** —— 40 分的创新性来自参与式叙事（浇铸 / 车削 / 工牌），加馆加的是宽度。一个做得深的好馆 > 五个空壳馆。

这两页补的是**叙事缺口**：序厅闭合"厂区外景 → 序厅 → 铸造馆"的进场序列；
通史馆补四层体验里唯一没有载体的第 02 层「看懂 · 铁流凝变」。

## 做什么

### ① 序厅 `#/entrance` —— 轻量三维，1 件雕塑 + 1 间暗厅

- 唯一主角是 **《铁流凝变》雕塑**：长 **22 m**、高 **11.5 m**，1:1，青铜 `#6B5B4A`。
  形态必须读作**「从左上向右下倾泻的流束」**，规格 §1.3 给了 5 个必须齐备的可辨认特征（样条主束 / 半径由窄变宽 / 扁截面 / 落点铺展 / 飞溅碎片）。
- 场景其余部分**刻意留白**：地面 + 后墙 + 一组光源。**不做**侧墙 / 顶棚 / 灯具模型。
- 光照：`HemisphereLight` 极暗底 + **一束顶部单向聚光（强度 3.2）**为唯一主角光。暖色只由聚光产生 —— 它是**凝固的**钢水，不要给雕塑上橙色材质。
- 机位两预设：`default` `[0,2.2,16]` → `[0,5.2,0]`；`sculpture` `[6.4,3.4,7.2]` → `[0,4.6,0]`。
- 页面结构复用 `#/hall` 骨架（HUD / 药丸 / 热点药丸 / 信息卡 / 说明条），**但不要小地图**，改为底部居中的「进场序列」`厂区外景 › 序厅 › 铸造馆`（序厅高亮橙色）。

### ② 通史馆 `#/history` —— **2D 长卷，不做三维**

- **8 个时间轴节点**（`1953–1957` / `1955` / `1957` / `2007` / `2018` / `2024` / `同期·人与物` / `今天`），
  年份、标题、正文在规格 §2.2 里**逐字给出，直接抄，不许改写、不许补编年份**。
- 版式按规格 §2.3 的横向栅格：内容左界 `x=120`、脊线 `x=140`、节点内容 `x=190`（宽 1060）、右栏馆体信息 `x=1000 w=320`（右对齐）、长卷轨 `x=1336`。
- 颜色**全部走 `tokens.css` 变量**，不得硬编码十六进制。铁水橙只用在眉标 / 关键年份（1957）/ 关键节点点 / 长卷指示 / 主按钮。
- **结尾主按钮（2026-09-18 二次裁定）**：`观看铸造馆 →`，**去 `#/hall`（铸造馆）**。
  原始文案 `今天，由你点火 →` 与落点 `#/cast` **均已作废**（理由见 `ENTRANCE-HISTORY-SPEC.md` §2.5）：
  长卷结尾要去的是"下一站"（铸造馆），不是绕过铸造馆直接跳进浇铸页。
  按钮 class 保持 `timeline__cta`，`data-go="hall"`；页面级 `[data-go]` 委托已能路由，**不要新增分支**，也**不要**把这枚按钮做成去 `#/cast` 的。

### ③ 场馆导航接线（五个药丸的最终行为）

| 药丸 | 行为 |
|---|---|
| 序厅 / 通史馆 / 铸造馆 | `go('entrance')` / `go('history')` / `go('hall')` 正常切页 |

## 硬约束

1. **铸造馆已冻结**（`SCENE-LAYOUT-FIX-SPEC.md` §10.10）：本轮**不得改** `props/lathe.js` / `props/toolcart.js` / `props/cupola.js` 的任何数值，不得改 `HALL_VIEWS` 八个预设，不得改 `layout()` 的任何阈值。
2. **`mountViewport` 的默认参数不得改**。序厅必须**传参**实现（`buildScene` / `cameraPos` / `target` / `debugKey` / `views`），默认值保持现状 → 保证铸造馆与浇铸页零回归。
3. **`props/sandboxes.js` 一行都别动**（浇铸页复用）。
4. **贴图 0 增量**：本轮不引入任何新贴图资源，《铁流凝变》不做表面纹理（纵向流线用几何凸棱实现）。全站贴图数保持 5。
5. **雕塑必须 merge 成 1 个 mesh**，draw call 只 +1，不得拆成十几个 mesh。
6. **机位预设钳制式**：`|pos − target| ≥ minDistance + 0.05`（本项目 `minDistance = 6`）。
   **近观读数必须在 `setView()` 之后取，不得用坐标直算** —— 直算值会被 `controls.update()` 钳制改掉，差一档。
7. **不要写 `Scene.environmentIntensity`** —— 那是 three r163+ 的 API，本项目锁 `^0.160`，写了静默失效。沿用逐材质 `envMapIntensity = 0.25`。
8. **不要用 `Math.random()`**（除既有粉尘外），不要引入付费依赖。

## 环境坑（本项目已知，别再踩）

- **AI shell 缺 `ls`/`find`/`head`/`dirname`**（精简 PortableGit）：**命令不要用管道 `|`**，管道右侧一崩整个命令假报失败。

- **Edge 持久化 profile 会回放旧 `index.html`**：截图 URL 加 `&t=<epoch>` 击穿缓存。
- **同一文件的多个 Edit 不能并行调用** —— 后一个会整文件覆盖前一个，必须逐条串行。
