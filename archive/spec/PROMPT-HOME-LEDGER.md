### 2.3 滚动驱动（**只允许一个监听、一个 CSS 变量**）

```
--ledger-p   写在 section[data-ledger] 的 style 上，0…1，钳位
p = (scrollY - sectionTop) / (sectionHeight - innerHeight)      // sectionTop 用文档绝对坐标
```

**分段（写死，不要改成"是否进入视口"）**：

| 屏 | p 区间 | 备注 |
|---|---|---|
| 1 | `[0.00, 0.30)` | 屏内进度 `pl = clamp(p/0.32, 0, 1)` → 格子浇满比例 |
| 2 | `[0.30, 0.63)` | 屏内进度 `pl = clamp((p-0.30)/0.33, 0, 1)` → 7 个人形由下而上依次出现（每人 0.1 带宽） |
| 3 | `[0.63, 1.00]` | 屏内进度 `pl = clamp((p-0.63)/0.37, 0, 1)`；前 50 格在 `pl` 0→0.4 依次点亮，第 69 格在 `pl ≥ 0.85` 亮起 |

**过渡**：相邻屏在边界 ±0.03 的带内交叉淡入淡出（**只动 `opacity`，不要位移/缩放**）。

#### 实现约束（**这是硬要求，不是建议**）
- **只允许 1 个 `scroll` 监听器**（`{passive:true}`），并且 `dispose()` 里对称 `removeEventListener`。
  不许出现第二个监听器、不许 `IntersectionObserver` + `scroll` 混用。
- **屏内进度、浇满比例、人形次序、年条点亮**全部走 CSS：
  一个变量 + `calc()` / `clamp()` / `mask-image` 推导，**不要逐格设类名、不要 `forEach` 写 style**。
- 1,000 个格子必须是**同一层元素**（`display:grid` + `aspect-ratio:1`），
  浇满用一层 `mask-image: linear-gradient(to top, #000 calc(var(--ledger-pl)*130% - 30%), transparent 0)`
  或等价手法 —— **不要 1,000 次 DOM 写操作**。
- `prefers-reduced-motion: reduce` 时：**直接写 p=1 的终态、不装监听器**（沿用现 L137–L142 的做法）。
