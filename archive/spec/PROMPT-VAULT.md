## ⚠️ 四条最容易做错的地方，先说

### 1. 徽记区**不是一张图片**，是一段数据驱动的 canvas（这条最重要）

画稿 S05 那一格是一张 **688×420 的灰色占位图**（画布节点 `3:244`）—— 那是画布阶段没有真实产出时的占位，
**不是设计意图**。照抄成 `<img>` 或一块灰底 div 就是把这页的核心做没了。

它是一枚**圆形铸造徽记**：外圈 12 格刻度环（按 `unlocked` 点亮）+ 环内**铸件轮廓** + 底环 36 根装饰刻度线。
全部由已解锁数据决定，**零随机**。

**用 `<canvas>` 画，不用 SVG。** 理由不是性能，是**分享海报**（§8）要用 Canvas 2D 重绘整张卡 ——
如果徽记是 SVG，就得维护两套绘制代码，迟早不一致。所以：
**抽一个 `drawEmblem(ctx, x, y, size, data)`，页面上和海报上调用同一个函数。**

环内画哪种铸件轮廓？取 `unlocked` 数组里**序号最小的砂箱**，查它的 `casting` 字段：
`flange` → 法兰 / `bed` → 床身 / `valve` → 阀体 / `gear` → 齿轮。
语义是**你最早浇出的那件铸件** —— 有纪念感，且**不需要新增任何存储字段**。

### 2. 画稿那 4 张衍生品卡**全亮是示意，不是规则**

`§7` 定了门槛：**≥ 3 件解锁「工牌实体卡」，≥ 8 件解锁「劳模语录卡」**。
画稿是在 `3 / 12` 的状态下把 4 张全平铺点亮的 —— **必须补锁定态**：
名称降为 `--c-text-muted`、说明降为 `--c-steel`、右上角一行 11px 徽标 `已解锁 3/12` / `已解锁 8/12`。
**不做毛玻璃、不做锁形图标** —— 用降对比 + 一行小字，和场馆导航「· 筹备中」是同一手法。

### 3. 海报**不要**去截三维帧

`STEP3 §6.2` 写的路子是「铸件缩略图开箱后截帧，`toDataURL` 用 `preserveDrawingBuffer: true`」——
**这条路走不通**：`viewport.js` 的渲染器**没有开 `preserveDrawingBuffer`**（实测确认），现在取帧会拿到空图；
打开它又有性能代价，而且要求三维场景仍在渲染 —— 可你离开 `#/cast` 后场景已经 dispose 了。

**用 Canvas 2D 画一张新的**：1080×1350（4:5，微信 / 小红书友好），
底色 `--c-bg` → 徽记（**复用 `drawEmblem()`**）→ 姓名 64px Bold → 工种·等级 28px `--c-iron`
→ 三值 40px Inter Bold 横排 → 编号 24px Inter `--c-steel` → 卡头标签 → 底部 `炉火不灭 · 2026`。

⚠️ **必须先 `await document.fonts.ready` 再绘制**，否则中文字形回落成默认字体。
⚠️ `toBlob` → `URL.createObjectURL` → 动态 `<a download="工牌-NO.000137.png">` → **用后 `URL.revokeObjectURL`**。
⚠️ **同数据两次导出必须逐像素一致**（零随机）。

### 4. `n / 12` 的**唯一来源是 `im.cast.unlocked` 数组长度**

现状 `im.badge.unlocked` 存的是**字符串** `"3/12"`（`cast.js` L476）。
本页的 `n` **一律以 `im.cast.unlocked` 数组长度为准**；
若二者不一致（旧数据 / 手工改过），**以数组为准，并把 `badge.unlocked` 回写成 `${n}/12`**。

## 页面结构（1440×900，横向两栏）

**这一页没有 HUD、没有场馆导航** —— 画稿如此：它是"抵达终点"的**静止页**，不是展厅。
出口由右下按钮行承担。

| 栏 | 宽 | padding | 内容 |
|---|---|---|---|
| 左栏 · 藏品展示 | **620**（固定） | 56 | 藏品卡（**400×560**，水平居中）+ **馆藏图鉴带**（规格新增） |
| 右栏 · 功能与衍生 | `fill`（= 820） | 56 | 眉标 / 标题 / 正文 / 衍生品宫格 / 按钮行 |

**左栏高度核算必须成立**（否则图鉴带会被挤掉）：
`56 + 560(卡) + 22(gap) + 20(图鉴标题行) + 164(图鉴 2×78 + gap 8) + 56 = 878 ≤ 900` ✓（余 22 px）

**兜底**：若在 375px 或浏览器字体差异下溢出，**优先压缩「卡 ↔ 图鉴」的 gap（22 → 16）**，
**不要缩藏品卡**（400×560 是画稿定值）。

### 馆藏图鉴带（规格新增，左栏底部）

### 衍生品宫格（画稿 240 宽 → **裁定改为 2 列铺满**）

**画稿实测的问题**：4 张卡各 240 宽，右栏内容宽 708 → 只能排 2 列（`2×240 + 16 = 496`），

## 环境提醒
