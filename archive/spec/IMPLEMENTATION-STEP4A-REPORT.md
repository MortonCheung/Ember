## 6. 偏离本规格处（逐条，均为**实现方判断（未走规格）**）

| # | 偏离 | 原因（实测驱动） |
|---|---|---|
| 1 | §2.2 `smoothstep` 剖面 → **C1 单调三次 Hermite（Fritsch–Carlson）** | smoothstep 每个关键帧导数为零，关键帧一密就"平-陡-平"起皱，逐站位法线角被抬到 8–23°；C1 曲线同为平滑非线性、不过冲，满足 §2.2"非线性不读作木梁"的意图 |
| 2 | §2.2 `getPoint/getTangent` → **弧长采样 `getPointAt/getTangentAt`** | 参数均匀采样在控制点间距不均处把相邻站位挤到 0.05 m（正常 0.6 m），退化 quad 法线翻转 177°——这是规格未写明的隐含坑 |
| 3 | §2.2 之外新增**截面落地滚转**（u∈[0.55,1] 宽度轴渐转向 z，量 0.55） | 不滚转时宽度方向 ⊥ 流向且竖直，主带落地段是一条"竖着的绸带"，要么穿地要么读作鱼尾；滚转后摊成水平薄片 = "钢水落地铺开" |
| 4 | §3 材质：metalness .85→**.75**、roughness .26→**.38**、envMapIntensity .55→**4.5**（entrance.js 覆写） | E5′ 实测 .85/.26/.55 时 20 点仅 1 点达标（min Δ7.6）：高 metalness 镜面只反射 RoomEnvironment 暗地板。逐档 sweep（0.55→1.6→3.0→4.0→4.5）后 4.5 为 20 点全过且保住青铜质感的档位 |
| 5 | §4 Key 聚光 angle .34→**.52** | .34 锥角在 20 m 投距只盖 ~7 m 半径，主带右半在锥外，E5′ 右侧采样点全灭 |
| 6 | §4 补光 0.18→**0.45** | E5′ 暗部采样点亮度不足 |
| 7 | §2.1/§2.2 形态参数与规格字面不同（BAND_PTS 12→13 点、W/H 关键帧、分流舌 2.6→1.8 m、落点散开收拢） | 依据 S09 基准图校形：消除"垂腿"与"平台背"；尾段加过渡控制点抹平曲率尖峰（否则滚转标架 B 轴在两站位内摆动过快，表面折翻、法线翻转 169°）。构造法本身（连续样条 + 40×8 环点 + 索引成面）严格按 §2.2 |
| 8 | merge 后**整体钳回贴地**（分流舌逐条同款，主带尾部 CatmullRom 过冲实测 −0.04） | E2.ground 容差 ±0.01；钳制后冠基座离地 ≤5 cm，该尺度不可见 |
| 9 | E1′④ 检测口径细化：max quad step 全带扫 + 逐站位中位数佐证 | §7 只说"法线不得 >25° 突变"，未定义扫描口径；中位数用于区分"环台阶"（整环同折）与"单边退化"（局部折） |

除上表外：光照 5 灯其余参数、地面/后墙/踢脚线、三预设坐标、页面结构均**逐字照抄规格**；无 `Scene.environmentIntensity`、无后处理、无 `Math.random`、贴图 0 增量、merge 成 1 mesh。
