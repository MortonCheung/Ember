## ⚠️ 三条最容易做错的地方，先说

### 1. 滑杆初值**不是**画稿上的 620 / 0.32（这条最重要）

画稿 S04 显示 `主轴转速 620 r/min` / `进刀量 0.32 mm/r` —— 但它同时显示 `正在录制` + `本局用时 02:14`，
**那是「车削进行中」的一帧，不是初始态**。那两个值是进行中的读数。

而且 `620` 在 `n∈[560,760]` 内、`0.32` 在 `f∈[0.20,0.40]` 内 —— **都在理想窗口里**。
照抄当初值 ⇒ 玩家一个滑杆都不动就是满分参数 ⇒ 得到 **100 分**。**这是设计缺陷，必须避开。**

**初值定为 `n = 420 r/min` · `f = 0.52 mm/r`**，两个参数各踩一个方向（转速偏低 / 进刀量偏高），
让玩家一眼看出"两边都要调"。不动手直接开车的落点是 **76 分、不入榜**（算例见规格 §7.4）——
与浇铸那边「不动手 72 分」同量级，这才是对齐的做法。

> `620` 是 C620-1 机床型号的呼应彩蛋，**不要从画稿上抹掉**；它只属于"进行中"那一帧。

### 2. 双人是**同屏**，不联网

`STEP3 §9` 明写「无需后端 · 无网络请求」。所以"双人"= **两名同学共用这一台展厅设备**。

- 徽标文案：画稿 `已连接 2/2` → **`双人协作模式 · 同屏操作`**
  （`已连接` 暗示联网握手，本项目没有网络层，跟「· 筹备中」是同一种**诚实降级**）
- **不做人数检测**（做不到，也不该做）：两个滑杆始终都可操作，协作分照常计算。
- 单人玩也成立：一个人一手一个滑杆，先后调整的时间差就是"配合度"。

### 3. 计时终点是**动画结束**，不是点击时刻

`§8.1` 只写了起点（「计时从第一次调整参数开始」），**没写终点**。
裁定：**终点 = 车削动画播放完毕**。否则 3600 ms 的动画时长对所有人免费，而"等工件车完"是真实成本。

- 起点 = 首次 `input` 事件；若全程未调整就点按钮，起点回退为点击时刻
- 入榜门槛：质量分 ≥ 60 **且** `t ≥ 10 s`（低于 10 s 不入榜，但分数照常显示）

## 评分引擎（照 `§8.2`，逐位实现）

```
表面质量：扣 = 0
  n < 560 : 扣 += min(40, (560 − n) × 0.35)      // 积屑瘤
  n > 760 : 扣 += min(30, (n − 760) × 0.30)      // 刀具磨损与颤振
  f > 0.40: 扣 += min(45, (f − 0.40) × 120)      // 刀痕粗
  表面质量 = max(0, 100 − 扣)

尺寸精度：m = n × f
  m > 304 : 扣 = min(35, (m − 304) × 0.35)       // 让刀、尺寸超差
  m < 112 : 扣 = min(25, (112 − m) × 0.20)       // 让刀不足
  尺寸精度 = max(0, 100 − 扣)

用时：clamp(round(50 / t × 100), 0, 100)          // 50 s ⇔ 赵国友的 50 分钟，不要改

总分 = 表面 × 0.45 + 尺寸 × 0.35 + 用时 × 0.20     // 取整只在最后一步
```

**协作分**（0–100，**不计入质量分**）：

```
协作分 = 100 − min(30, 累计时间差(s) × 2) − min(40, |f − 0.30|/0.10 × 20 + |n − 660|/100 × 20)
```

- **累计时间差** = 相邻两次参数调整的时间间隔之和。协调得好 ⇒ 调整几乎同时 ⇒ 时间差小。
- 理想带：`f ∈ [0.20,0.40]`（中值 0.30 / 半带宽 0.10）· `n ∈ [560,760]`（中值 660 / 半带宽 100）
- 下限 0，不出现负值

**引擎纪律**：纯函数 `score({n,f,t,adjustments}) → {total, subs, collab, rank, inBoard}`；无 DOM / 无存储 / 无随机 / 无时间依赖；
`clamp` + `Number.isFinite` 在入口统一做；非法值回落 **`n=420`、`f=0.52`**（注意不是 §10 E3 那套浇铸值）；`t ≤ 0` 回落 `t=600`。

**等级映射**：**沿用 `§6.1` 那张表**（与浇铸共用），**不要另立一套**；`< 60` 走「待复检」不发等级。

### 四组算例（必须逐位一致）

| # | `n` | `f` | `t` | 表面 | 尺寸 | 用时 | **总分** | 协作分 | 入榜 |
|---|---|---|---|---|---|---|---|---|---|
| ① | 420 | 0.52 | 3.6 s | 45.6 | 100 | 100 | **76** | 20 | 否 |
| ② | 660 | 0.30 | 50 s | 100 | 100 | 100 | **100** | 100 | 是 |
| ③ | 660 | 0.30 | 90 s | 100 | 100 | 56 | **91** | 100 | 是 |
| ④ | 1200 | 0.80 | 600 s | 25.0 | 65.0 | 8 | **36** | 20 | 是（强制结算） |

① = 不动手的落点（同规格 §7.4）。**协作分算例统一假设「累计时间差 = 0」**（两次调整同时发生）。
④ 的 `表面 = 100 − 30 − 45 = 25`：`n = 1200 > 760` 走**磨损颤振**分支（0.30 / 上限 30），
**不是**积屑瘤分支（0.35 / 上限 40）—— 两分支互斥，别取错。

## 车削动画（固定 **3600 ms**，与 n、f 无关）

**必须固定时长**，否则用时口径不公（慢参数 = 长动画 = 双重惩罚）。

| 段 | 时长 | 内容 |
|---|---|---|
| A 起动 | 0–500 ms | 卡盘带工件起转（0 → 目标 ω），刀架进入 |
| B 切削 | 500–3200 ms | 刀架沿轴向走完 6 级台阶；切屑粒子从刀尖落 |
| C 收刀 | 3200–3600 ms | 刀架退回，主轴降速停转 |

**参数 → 视觉映射（三条都要单调、可测）**：

| 参数 | 映射 | 说明 |
|---|---|---|
| `n` | 视觉角速度 `ω = n / 400` rad/s（0.50…3.00） | **必须降速显示** —— 真实 620 r/min = 10.3 转/秒，60fps 下就是一片糊。HUD 显示真实 r/min |
| `f` | 台阶半径偏差 `ΔR = (0.30 − f) × 0.02` m | `f` 小 → 直径偏大（让刀不足）；`f` 大 → 直径偏小（让刀） |
| `f > 0.40` | 台阶面出现周向**刀痕暗环**，数量 `clamp(round((f−0.40) × 25), 1, 8)` | 把「刀痕粗」变成看得见的东西 |

- 刀架轴向位置**只由动画进度驱动**：`z = −0.18 + progress × 0.36`（`easeInOutCubic`），**与 n、f 无关**
- 工件：**毛坯 = 等径大圆柱 `R = 0.085`**，车削中逐级缩到标称 `R_i = 0.075 − i × 0.010`（i = 0…5，6 级）
  —— **做成 1 个 `BufferGeometry`（6 段 × 32 边），update 里改顶点** ⇒ **工件只占 1 个 draw call**
- **零随机**：切屑与刀痕全部由确定性函数（`sin` 哈希，同 cast 页做法）给出，**禁 `Math.random`**

## 录制与回放（画稿承诺了，不能做成装饰）

- **录制**：从计时起点按**固定 100 ms 间隔**采样 `{t, n, f}` 存内存数组
- **回放**：结算态启用右栏**按钮行的第 2 枚 `回放本局`**（画稿未画 → 规格新增）。
  点击后 ① 视口按记录时间线**重演**（同一套 `update`，参数源换成记录）；② 计时值下方**叠加 `n`/`f` 双折线**（SVG 或 canvas 2D，两色分别用 `--c-iron` 与 `--c-text-muted`）
- **同记录两次回放必须逐帧一致**

## 环境提醒

- 本机 AI shell 是精简 PortableGit：**没有** `ls` / `cd` / `dirname` / `tail`，**命令不要用管道**（会假报失败）
- 构建：`node node_modules\vite\bin\vite.js build`（cwd = `demo/`）
- 截图必须走 CDP（`tools/screenshot.py`）；Edge 的 `--screenshot` **静默失败**
- 本机自测脚本**必须在无代理环境**跑（沙箱代理会拦 loopback 返回 502）
- `python -c "..."` 里不要写反斜杠或反引号（bash 先吃一层转义 → `SyntaxError`）；写 `.py` 文件再执行
